# 链路真源注册表（chain_sources.txt）
#
# **为什么有这张表**（2026-09-17 用户追问「这是垂直切片么」→「切片的意义在端到端跑通吧」）：
#   契约原文 = `PRD/05-任务分解.md` **§二「垂直切片（每片 = 一条需求能端到端跑通）」** ——
#   **切片本来就是"链路"**，不是"模块"。而执行时它被降解成「本切片名下的 `ACC-*` 全绿」，
#   那些判据**全部钉在模块内的纯函数**上 ⇒ **链路的中间环节没有任何尺子**。
#   ⇒ 本表 = 把"端到端"从**口号**变成**可机读的度量单位**：每条链路指认自己的一节真源。
#
# **格式**：`<链路代码>|<链路名>|<从仓库根起的真源文档路径>|<节起始行前缀>|<节结束行前缀>`
#   · 多条链路可指向**同一节**（如 A/B/C 同指建档 §三）
#   · 「节」只服务 `C6 覆盖哨`（提取该节**代码块内**以 ①/②/… 开头的分支行）
#   · `C2 文档锚` 在**该真源文档全文**里查（宽松：锚落在同文件别节也算过）
#   · ⛔ 真源文档**只增不改语义**：真源一改，`C2` 就会报「锚找不到」⇒ 不会静默过期
#
# **链路代码命名**：建档三链路沿用 A/B/C；业务域链路用 `<域字母><序号>`；`X` = 跨域。
