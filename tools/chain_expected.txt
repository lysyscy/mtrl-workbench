#
# 状态（**只准变短** —— 分支落地了就把状态改成「已接」）：
#   已接     = 绿：落点存在，**且已核过生产调用方就在这条链路内**（`wiring_audit` 另兜"零调用方"）
#   接线缺   = **红**：零件写好了，但链路上没人调用它
#   缺       = **红**：这一步**根本没有落点**
#   形态不同 = 黄：实现了，但与文档写的那一步**形态不一样** ⇒ **待用户追认**（⛔ 不静默放过）
#
# 格式：`<链路>|<分支>|<文档锚（真源里的一段原文，归一化后匹配）>|<落点 path 或 path::名字 或 —>|<判据>|<状态>`
#   ⚠️ 判据写 `缺：…` ⇒ 该行本身就是一条**待补判据**的缺口（红）；写 `不可断言:…` ⇒ 黄。
