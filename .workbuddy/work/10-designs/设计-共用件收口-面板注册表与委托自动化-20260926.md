## 〇、为什么是这四件（用户两次报障都出在同一处）

本仓的壳有一套「共用件（`projPanel` / `tmBtn` / 表格件…）＋ 动作表 `ACT` ＋ 两条全局委托」的结构。
问题在于：**共用件只提供"渲染"，而"状态 / 登记 / 收尾"仍散在每个调用点** ⇒ 每加一处就要人记一次，
漏了就静默坏（不报错、闸门也看不见）。2026-09-26 两次现场：

| 现场 | 症状 | 根因 |
|---|---|---|
| 通用导入面换共用面板 | **展开后关不掉**（点页面别处不收） | 「点面板外部自动收起」是**逐个列 13 个名字**的，漏登记 `IMP.pjOpen` |
| 同一次 | 单选点完是否要自己收 —— 要问才知道 | 6 个单选调用点**各写** `XxxPjOpen=false`，规则不在共用件里、也没有判据 |

⇒ 结论：**把"状态与收尾"搬进委托层／共用件**，让"名单"与"自觉"消失。

## 一、`#1` 面板展开态注册表（推荐先做 —— 一次消掉上面两个现场）

### 1.1 机制（落在 `index.html` 的共用件区，紧挨 `projPanel`）

```js
/* ⭐⭐ 浮层面板展开态的**唯一主人**：调用点不再各持一个 `let XxxPjOpen`。 */
const PJ_OPEN = {};
const pjIsOpen = k => !!PJ_OPEN[String(k)];
const pjToggle = k => { const s = String(k); PJ_OPEN[s] = !PJ_OPEN[s]; render(); };
const pjClose  = k => { const s = String(k); if (PJ_OPEN[s]) { PJ_OPEN[s] = false; return true; } return false; };
```

① **`projPanel` 自己派生 key**（⛔ 调用点不用传）：`const key = String(c.pickAct || '').replace(/Pick$/, '')`
   ⇒ 每个面板的 key 唯一（`ledPjPick` ⇒ `ledPj`），**13 个调用点的 cfg 一行都不用改**。
② 面板里的 `radio`/`checkbox` 加 `data-pj-key="${key}"`。
③ 委托层（`actions.js` 的 click 委托）在跑完 `ACT[a](t)` 之后补一句 **自动收起**：

```js
/* ⭐ 单选面板点一下就收（2026-09-26 用户要求）—— 由**委托层**做，⛔ 不靠调用点自觉。 */
if (t.dataset.pjKey && t.type === 'radio') { PJ_OPEN[t.dataset.pjKey] = false; render(); }
```
   ⚠️ 多选面板渲染的是 `checkbox` ⇒ 天然不收（"点了不关、好连续勾"是既定行为）；单选渲染 `radio` ⇒ 自动收。
   ⭐ 这样**连"哪块面板是单选"都不用登记** —— 靠 `radio/checkbox` 这个事实本身。
④ **「点面板外面收起」名单整个删掉**，改成遍历注册表：

```js
document.addEventListener('click',e=>{
  const any = Object.keys(PJ_OPEN).some(k=>PJ_OPEN[k]);
  if(!any && mp.open===null) return;                    // `mp` = 年月选择器（另一套，见 #4 再议）
  const inEl=cls=>!!(e.target&&e.target.closest&&e.target.closest(cls));
  let ch=false;
  if(!inEl('.pjwrap')) Object.keys(PJ_OPEN).forEach(k=>{ if(PJ_OPEN[k]){ PJ_OPEN[k]=false; ch=true; } });
  if(mp.open!==null && !inEl('.mpwrap')){ mp.open=null; ch=true; }
  if(ch){ render(); if(lastModal&&lastModal.reopen) lastModal.reopen(); }
});
```

## 三、`#3` 写动作后「全标脏」自动化（`TAIL-78` 实测：漏标一路 ⇒ 切页看旧数）

**现状**：每个写动作自己写 `LOADED.clear()`（`test_imp_shell` 现在只是**巡视**它写没写）。
**目标**：写动作走**统一出口**，出口里自动全标脏：

```js
/* 所有写动作经它 —— ① 报错按既有口径转中文；② 成功后**自动全标脏**（⛔ 调用点不再各写一遍） */
async function writeAct(fn, okMsg) { const r = await fn(); LOADED.clear(); toast(...); return r; }
```
⚠️ 实施要点：① 全站写动作**逐个换出口**（`ACT.*Save/Add/Del/Ok/Commit/Rollback…`）—— 这是**大改**，
   建议**先只收口"跨页写"的那几类**（导入/回滚/付款/抓取），其余保持现状并登记；
② 判据：`LOADED.clear()` 只许出现在出口里（`grep` 到别处即红）；
③ ⚠️ 别把"只有本页标脏"的动作也硬套全标脏 —— 那会让每次保存都全量重拉（性能）。
