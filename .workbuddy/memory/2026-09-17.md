### ④ 两处新踩的坑（都记进技能 / 细则）
1. **Python `bytes` 字面量不能含非 ASCII** ⇒ 变异脚本片段含中文时**必须写 `str` 再 `.encode("utf-8")`**，
   否则 `SyntaxError: bytes can only contain ASCII literal characters`（报在脚本自身、极易误判成"变异点写错"）。
2. **SQLAlchemy 判等号要认 `operator.__name__ == "eq"`** —— `str(operators.eq)` 得到的是
   `<built-in function eq>`（**不是 `"="`**）⇒ 用字符串比会**永远不命中**，
   测试桩的 where 过滤会**静默失效**（正是"看着像在过滤、其实没过滤"）。已写进 `m09_helpers.py` 注释。
3. 顺带：`render_list_page` 的 `filter_action` 会**整段包一个 `<form>`** ⇒ 筛选栏内的控件**不能再自己包 form**
   （否则嵌套表单）；写动作的 POST 表单要挪到 `data_html` 里。
