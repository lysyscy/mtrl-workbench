```

├─ README.md                   # 起停与自检命令（不写口径、不写进度）
├─ .env.example                # 连接串 / i8 / 打印机 / 端口（真值不进库）
├─ backend\
│  ├─ requirements.txt
│  ├─ pytest.ini
│  ├─ alembic.ini              # 纯 ASCII（坑 1.1-1）

│  │  ├─ main.py               # FastAPI 装配（中间件顺序见坑 1.5-16）
│  │  ├─ core\                 # 配置(.env) · DB会话 · **金额口径唯一出口** · 日志 · 鉴权

│  │  ├─ mod11_jc\             # 集采台账（MOD-11）
```
