# 共享壳、首页与集采台账标杆

模式为 Operate。PR-W1a 用方向 A「精工深墨松绿」定下共享壳、首页和集采台账的桌面标杆。主题和业务依据分别见[设计规范](../../DESIGN.md)、[前端设计与文案](../../docs/guides/frontend-design.md)和[当前需求](../../docs/requirements.md)。后续波次沿用视觉规则，按各页工作内容决定表格、工具区与弹窗的尺寸。

## 桌面四档

| 视口 | 界面大小 | 主要核对内容 |
| --- | --- | --- |
| 2560 × 1440 | 大一点 1.12× | 首页居中限宽 1520px，三个待办并排。集采使用可用宽度，操作栏和筛选栏各一行。 |
| 1920 × 1080 | 标准 1.0× | 三张待办并排。集采操作栏和筛选栏各高 ≤48px，表体 36px，表头 34px。 |
| 1440 × 900 | 最大 1.4× | 打开外观面板。工具区可换行，合计与横向滚动条可达。侧栏滚动到底可进入规则配置和用户管理。 |
| 960 × 1000 | 标准 1.0× | 默认 56px 图标侧栏，一键展开至 224px。独立预览标识在收窄时移到页标题旁，横向滚动由表格承接。 |

字号档按比例放大文字、控件和表格几何。四档的文档横向溢出目标为 0px，金额和合计在自动列宽下完整可见。

## 共享壳与首页

- 侧栏展开宽 224px，收窄宽 56px。视口 ≤1080px 时默认收窄，手动切换在当前工作区有效。短窗侧栏可纵向滚动，顶部保留切换按钮。跟随系统减少动态效果。
- 外观面板优先呈现「标准」「大一点」「更大」「最大」四档。名称读取服务端清单，档位选中后保存并重读当前账号。单主题显示「当前主题：精工深墨松绿」。「查看明细」仅用于展示控件尺寸。
- 首页保留「归属待指定」「集采未关联合同」「撤单但有牵涉」三个真实待办和对应入口。已读且大于零的操作用松绿实底，零待办用中性描边。未知时保留计数占位，并以中性色显示图标、待读取状态和操作入口。
- 页面错误区采用 `flow` 布局，沿现有重新加载及草稿保护入口处理。全局撤销、重做继续显示动作与影响范围。

## 集采台账

- 1080P 和 2K 下，操作栏、批量勾选栏和筛选栏各有明确位置。高频工具、贸易列开关、搜索和导出入口直接可达。批量栏显示勾选数量及列表外数量，表头复选框表示当前筛选结果的未选、半选和全选。
- 表格使用 36px 行高和 34px 表头基准。发票、付款和贸易公司发票金额与底部合计共用数值列和「子表」控件列，金额文字右缘差 ≤2px。无贸易公司但显示贸易列的记录也按同一位置对齐。
- 表格溢出时，原生横向滚动条位于固定合计下方。轨道和滑块分别用 `--sf2` 和 `--bd3`。宽度变更由 AG Grid 处理，手调、按账号记录列宽和恢复默认沿原入口运行。
- 保留 `48951265` 的付款方式首击。滚动后对延迟渲染的控件单击即可打开，控件、标签和滚动位置保持稳定。
- 八个验收弹窗为材料名、抓取采购合同、甲方单位分类、供应商发票子表、付款子表、从付款域引用付款记录、编辑合同备注、导出打印版。贸易公司发票沿供应商发票的子表布局。材料名单字段弹窗在标题下显示项目和完整合同编号，无编号时显示已有的供应商及合同日期。

## 业务护栏

| 编号 | 后续复用约束 |
| --- | --- |
| R01 | 颜色来自主题角色。金额正负照常显示，状态有文字或形状。 |
| R02 | 四档只放大。金额完整显示，导出按 `ROUND_HALF_UP` 保留两位小数，分别处理空值、零及未知。 |
| R03 | 沿 `flow`、`fill`、`split` 页面布局和 `compact`、`scroll-body`、`pane` 弹窗布局。弹窗按 88dvh 上限安排滚动，批量付款沿 65% 与 35% 的双表分配。 |
| R04 | 手调列宽由 `GridWidthOwner` 按账号和表保存，恢复入口位于表头。 |
| R05 | 指定单行策略限通知书、集采及机械费。自动列宽保护规定的编号和日期。 |
| R06 | 逐格保存保持静默，失败后只在对应位置处理输入。未知结果先重读核对。 |
| R07 | 保留离格保存、回车确认、中文输入法和浏览器复制粘贴。键盘与跨格操作沿组件的默认行为。 |
| R08 | 撤销与重做保留 20 步。弃稿确认用统一文案，安全焦点落在「继续编辑」。 |
| R09 | 应用内切页保留筛选、勾选、排序、滚动及草稿，离页关闭定位浮层。刷新和换号沿原重置规则，集采子表按会话草稿规则恢复。 |
| R10 | 等待读取使用占位及状态反馈。金额与计数读到后再显示，交互响应系统减少动态效果设置。 |
| R11 | 通知书保留粘贴置顶、打印顺序、单条打印后清选、一键关联、直下导出、后台提醒及精简剔除回执。 |
| R12 | 欠款与流水独立保活。三卡藏零保负，逐月表合计贴末行，切项目保高并隐藏旧结果，草稿或结果待核实时暂停导出。 |
| R13 | 集采保留动态序号。账期提醒上限为 100 天，发票严格大于 110% 才警示。抓取回执留在本次窗口，打印沿独立模板。 |
| R20 | 首页只展示当前三个待办。项目类型只读，保留整行拖排和归档搜索。规则保留双标签定位，用户保留末位管理员保护，i8 的状态读回和外部取数各走现有入口。 |

## 验收证据

主检出的受管 `.artifacts/runs/mtrl-site-polish-plan-20261127/w1a-evidence/` 保存改前截图、`before/baseline-metrics.json`、采集脚本 `measure_w1a.py` 和 `after-final/`。在可丢弃真实副本上核对四档截图、两档贸易列、八个弹窗、字号隔离、表头半选、金额几何与侧栏长任务。滚动比较沿用同版 Chromium 和相同的 1200px 位移，1080P 与 2K 各采五次，平均帧间隔和 P95 的退化上限为 15%。

最终记录中，四档文档横向溢出为 0px，各子表金额与合计最大右缘差为 0px。1440px 与 960px 的横向轨道为 10px，滑块对比度为 3.86:1。1080P 操作栏和筛选栏分别为 43px、42px，2K 分别为 46.83px、45.83px。四档侧栏切换在常规和减少动效下均未捕获超过 100ms 的任务。源码和两条实际预览路由的 Impeccable 扫描均返回空数组。
