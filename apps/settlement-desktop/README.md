# 收发结存单机版

Windows 10／11 的 64 位电脑可双击 `收发结存.exe`。电脑须能访问所在单位的 i8。运行时、图形界面和报表模板随程序分发，生成报表无需安装 Python 或 Office。

1. 在 i8 用本人的账号把本月应报的项目加入「常用项目」。
2. 打开程序，选择电信、联通或内网线路，首次默认电信。填写账号、密码与报表单位名称，选择核算年月。点击「连接并读取常用项目」。登录可能使同一账号在其他设备上的会话下线。
3. 核对名单，点击项目可切换是否纳入。缺项就在 i8 补加，返回点「刷新常用项目」。常用名单只代表本账号已添加的项目。
4. 点击「生成收发结存报表」，选择 ZIP 的保存位置。每个有明细的仓库生成一份 Excel，另附一份包含全部明细与按仓汇总透视表的总表。

程序自动记住上次线路、账号、密码、单位名称、核算年月和报表保存目录。密码由当前 Windows 用户加密保存。读取常用项目后自动恢复该 i8 账号的勾选；新增的常用项目默认勾选。

## 维护与构建

使用独立的 Windows x64 Python 3.13 环境，装入 `pyinstaller pandas xlsxwriter openpyxl pydantic-settings httpx gmssl loguru pywin32`。从仓根调用该环境的 Python 执行以下命令，工作目录使用当次登记的 work 路径。第一条仅使用模拟 i8 回包和临时目录。

```text
python -B -X utf8 apps/settlement-desktop/check.py
python -B -X utf8 apps/settlement-desktop/build.py <工作目录> dist/收发结存单机版
```

构建复用工作台的 i8 登录协议、报表请求、原表解析和成品导出。构建时生成中性透视模板，仅随包分发登录加密所需的公钥和中性模板。
