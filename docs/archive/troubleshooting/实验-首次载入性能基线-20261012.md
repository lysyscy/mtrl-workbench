## 条件与边界

[用户] 只诊断与规划，不改产品代码、业务数据库、不重启、不推送。TAIL-313 的日期修正与防覆盖保持原样。

[实测] 起始 HEAD = 019263e16cffd003168c62a67a9b77b0c02d530a，工作区干净。测量发生在用户电脑的本机服务 http://127.0.0.1:8000；服务保持运行，未做冷服务启动。

浏览器为本机独立 headless Chromium 151.0.7922.34，1440×900，未登录，只读会话。既有浏览器控制工具因运行组件缺失启动失败；没有使用或清理用户既有浏览器缓存 / Cookie。

每个目标页创建新浏览器上下文，先打开 /app 并等初始 home 的 BOOTING 结束，再 go(目标页)。首次时间从 go 开始，等 PENDING / m05Refetching 结束及两次 animation frame；重复访问先回 home 再进目标页。刷新同一 tab 后重建壳 LOADED，保留该独立上下文 HTTP 缓存，重测目标页。三种各一条样本，非均值、非 P95；串行、无压测。

因此“首次”是**初始看板已完成后的模块首次访问**；新上下文的资源冷请求单独记录。重复访问体现壳内 LOADED 复用。不能把浏览器新上下文、刷新或独立 Python 进程当成服务冷启动。

探针用 fetch / Response.json 计时、Resource Timing 和 render 包装。fetch 到响应头包含服务处理与本机传输；Response.json 包含剩余下载、解压与解析，不能纯称 JSON CPU。render 是同步调用耗时，含字符串生成 / DOM 接线，不含所有后续布局与虚拟滚动过程。

## 后端拆解（独立进程，不是运行服务内 profiling）

直接执行已有四个读入口；每次事务通过 SQLAlchemy begin 事件设置 READ ONLY，库名校验为 mtrl_workbench。不运行 TestClient startup、迁移、导入或写入口。记录 SELECT 数、游标 execute 时间（**不含 fetchall / 类型解码 / ORM 物化**）、cProfile，以及当前 FastAPI 实际响应字段序列化与 gzip9阶段。

一次无 profiler 基线：inventory 函数 787ms / serialize 88ms / gzip 245ms；matrix 1103 / 22 / 4ms；big 531 / 5 / <1ms；extract 549 / 2 / <1ms。不同进程、连接预热、调度及 profiler 开销使这些数不能与浏览器响应头相减，亦不能直接代表服务内部各阶段的精确占比。

SELECT 次数为 3 / 6 / 11 / 4，游标时间合计约 41–51ms。未发现这些入口逐库存行 SELECT 的 N+1。inventory 查询 inv_adjustment 两次；big 重读少量 project / choice / manual；extract 重读 balances；属于可顺手收敛的小重复，非主耗时。

cProfile 的库存 list_details 约 0.57–0.65s：完整 ORM 取回 18,198 行，含 raw JSON 的解码与物化；to_row / 分类再走全部行。matrix 为 15 项目调用 _matrix_for，build_matrix 共 30 次，单仓矩阵仍扫描全来源数组。big 与 extract 各调用 load_amounts，它先取所有方向的完整库存 ORM，之后才筛入库、只使用四字段。EXPLAIN（未 ANALYZE）显示库存全量排序用主键 Index Scan，估计约 18,233 行；本轮不支持“缺索引”为主因。

## 只读原型与可信度

仅在诊断 Python 进程内替换读取函数：库存结果行投影排除 raw / created_at、避免 ORM 物化；提取仅 SELECT 原单入库的物料名、仓库、核算月、金额，仍调用原 extract_amounts。不改仓库产品文件或服务。

一组无 profiler 对照的函数时间为 inventory 787→509ms，matrix 1103→771ms，big 531→274ms，extract 549→80ms。是单次原型证据，**不是部署提速承诺**；前一版只 defer 两字段的实验收益不稳定，因此推荐明确投影而非默认给所有 ORM 消费者加 defer。

inventory / matrix / big 原始响应字节摘要一致。extract 的原始字节摘要不同而长度相同，最终按 JSON 键排序后的规范化摘要四项均相等，确认本次仅键顺序差异。最终复核一组函数时间为 inventory 705→582ms、matrix 1023→809ms、big 642→198ms、extract 593→72ms。两组均为单次且跨进程、有调度与预热差异，不能按比值预报页面收益。持久化证据仅含时间、计数、路径与摘要，不含数据行、SQL 参数、Cookie、连接串。
