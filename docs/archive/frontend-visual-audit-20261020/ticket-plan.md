# 全站界面精修：已批准拆分

状态：2026-10-19，用户批准13项拆分，并要求可通过个人工作流接续；本轮仅发布票，不开发正式功能。来源与逐页事实见[全站审计](spec.md)，不是第二个活跃票仓。

## 个人工作流接续

正式实施时显式调用 implement-solo-spec，从项目 docs/agents/workflow.md 定位同来源 execution.md，先核授权、当前票与依赖；本轮拆票不启动实施或统筹。共享组件改动须核实际调用者，按受影响范围选择隔离测试和内置浏览器复核；纯视觉和身份状态逻辑分清，保留既有业务契约。需要跨批累计集成时按该技能的条件读取 coordination.md，开工时固定实际执行基线；不因13张票自动创建子Agent或启动另一套收尾。

每票完成后在本票Comments留验证、发现关闭、未验与保存状态，按本仓工具销号；最后一票汇总实际整合风险，不重复未变化且仍有效的证据。当前只授权拆票，正式开发、真实写入及部署另按用户明确指令。

## 切片

## 01 共用弹窗键盘与焦点修复

**What to build:** 打开弹窗后能按可见层级用键盘完成操作，关闭后回到原触发位置。

**Blocked by:** None (can start immediately)

- [ ] 覆盖共用弹窗及规则编辑、集采子表等实际调用；提供可访问名称与对话框语义，初始焦点进入合适控件。
- [ ] Tab与Shift+Tab不进入背景，背景不可交互；Esc、关闭按钮和焦点归还保持可用，嵌套选择器与重绘不会丢失焦点或困住用户。
- [ ] 用键盘复现审计F01并验证修复，检查鼠标、可滚动长内容及关闭后操作；不修改业务保存、删除或权限规则。

## 02 过程资料与三类汇总宽表精修

**What to build:** 用户能读全月度会年月、辨认列组和输入范围，并方便定位各个独立汇总工作区。

**Blocked by:** None (can start immediately)

- [ ] 修复F02，完整YYYY-MM、最大常见金额、备注及带入标记都能辨认且不互相遮挡，不修改字段内容或计算。
- [ ] 过程资料弱化普通网格、突出列组与合计，六个机械输入仍容易发现；保留固定列及局部横滚。
- [ ] 收发结存、年度汇总和月度会可快速定位；各自时间、项目选择和三级表头保持，正常已对平标记降权但判平规则不变。
- [ ] 分别检查已有长内容、空状态、输入焦点和不同桌面宽度；原筛选、带入、计算与导出定向回归通过。

## 03 付款通知书精修

**What to build:** 用户能清楚定位通知书、金额和已选对象，顺畅执行原有批量处理与打印。

**Blocked by:** None (can start immediately)

- [ ] 按当前对象与批量动作整理顶部操作区，批量状态及动作对象清楚，保留原筛选和导出打印入口。
- [ ] 真实长项目名、供应商名、单据号与金额可辨；按本页内容确定列宽和行高，不全站统一压成34px或缩字。
- [ ] 检查勾选、取消、批量动作、排序重画、局部横滚及返回位置；原支付和打印业务不变，不执行真实支付或打印。

## 04 流水与欠款工作区精修

**What to build:** 用户能先判断欠款，再进入对应流水或台账，首屏不被重复概览占满。

**Blocked by:** None (can start immediately)

- [ ] 压缩三组概览的无效高度，给流水和台账足够阅读空间；必要时采用区段定位，保留汇总到流水的项目筛选逻辑。
- [ ] 长名称、金额、合计、空状态和较窄桌面下可辨，不靠隐藏关键业务列或缩字解决。
- [ ] 原项目筛选、截止口径、汇总金额、流水明细及导出定向回归通过，不改费用计算或业务数据。

## 05 集采台账精修

**What to build:** 用户能清楚核对合同、供应商和合计，并找到相关发票与付款子表。

**Blocked by:** None (can start immediately)

- [ ] 修复供应商频繁折行及合计文字纵排，整理首屏动作，金额与子表入口对应清楚。
- [ ] 保留现有发票子表尺寸和清楚的合计；两种导出保持独立入口、原范围与原契约，不混成一个导出。
- [ ] 检查真实长名称、多个子表、空状态、横滚及返回；原合同、发票、付款、结算操作定向回归，不产生真实业务写入。

## 06 项目档案精修

**What to build:** 用户能读清项目名称和归属，区分可改展示名与只读仓库名，并找到行操作。

**Blocked by:** None (can start immediately)

- [ ] 给项目标识及全名足够空间，长名称可读可编辑，排序、类型、编辑态层级清楚。
- [ ] 只读仓库名与可改展示名明确区分，输入和焦点仍可发现；行操作易定位，保留原排序和归属规则。
- [ ] 使用隔离数据检查长名称、普通行、编辑取消、保存和横滚；不改真实项目或新增权限。

## 07 库存单据与调整单精修

**What to build:** 用户能在大量单据中辨认对象、查看筛选状态并找到补正操作。

**Blocked by:** None (can start immediately)

- [ ] 按内容稳定单据号和规格列，横滚时仍能辨认当前对象，行操作可定位。
- [ ] 区分已启用筛选与闲置图标，保留Excel式列筛选、排序和调整归属，不改变匹配及金额口径。
- [ ] 检查长规格、空状态、多筛选、排序、横滚及调整入口；保存验证使用隔离数据，保留原导出与删除行为。

## 08 看板与i8接入层级精修

**What to build:** 用户能先看到待处理任务或当前取数结果，再按需查运行状态和历史日志。

**Blocked by:** None (can start immediately)

- [ ] 看板降低零待办权重，处理任务与运行状态分层；现有跳转保持，不增加重复统计。
- [ ] i8接入稳定标题、时间和动作列的阅读空间；当前结果优先，历史日志和详细错误按需展开，失败原因仍可获得。
- [ ] 保留会话影响等决策提示和关键后果；用成功、失败、长错误、无记录等隔离状态验证，不登录、踢会话或真实抓取i8。

## 09 特殊费用入口精修

**What to build:** 用户先看清当前项目当月操作，再进入批量填报，并能提前知道缺少哪些前置条件。

**Blocked by:** None (can start immediately)

- [ ] 当前项目动作与批量入口有明确主次；无手填项等缺失条件在入口附近说明，与实际可用性一致。
- [ ] 空表和有数据时布局清楚，自动项与手填项保持区别，不为美观虚造数据或改变填报口径。
- [ ] 隔离验证无手填项、有手填项、切换项目月份及批量入口；既有保存和计算规则保持。

## 10 导入与规则配置精修

**What to build:** 导入步骤和规则内容更容易阅读，同时保留所有写入确认及后果提示。

**Blocked by:** None (can start immediately)

- [ ] 导入减少重复容器与帮助权重，四步、预览、禁用原因和明确确认写入仍清楚，不改自动上传或自动入库。
- [ ] 规则按类别分组，长命中值自然换行或分项，保留删除与停用区别及对后续抓取的提示；编辑弹窗按内容定宽。
- [ ] 检查长规则、空状态、禁用、预览与取消；规则编辑、停用、删除和导入确认只在隔离环境验证。

## 11 主题选择可识别性

**What to build:** 用户无需悬停也能辨认主题名称，明确当前选中了哪一项。

**Blocked by:** None (can start immediately)

- [ ] 主题卡面显示名称和明确选中标记，保留已有可访问名称与选中语义，不只依赖颜色。
- [ ] 保留原配色、主题清单、字号选择和预览机制，不更换主题系统或放大预览图。
- [ ] 隔离验证不同主题名称、键盘焦点、选中与保存恢复及不同字号，不修改用户真实偏好。

## 12 用户身份反馈修正

**What to build:** 页面如实显示未登录、普通用户或管理员身份，用户能理解账号操作不可用的原因。

**Blocked by:** None (can start immediately)

- [ ] 修复F06：无身份时不显示空姓名的当前登录普通用户；有身份时姓名和角色与真实会话一致。
- [ ] 禁用操作及其原因可辨，保持既有权限、账号动作和安全边界，不展示密码或放宽权限。
- [ ] 隔离验证未登录、普通用户、管理员以及登录状态变化；相关页面与后端拒绝边界仍有效，不写真实账号。

## 13 全站视觉复审与收口

**What to build:** 用户在所有已调整页面得到一致可读的数字、间距、焦点和状态反馈，原有业务流程保持。

**Blocked by:** 01、02、03、04、05、06、07、08、09、10、11、12

- [ ] 逐项对照原审计F01至F06与页面表，记录已修、保留、不适用和未验，覆盖前12票真实修改而非仅审CSS差异。
- [ ] 对相关页面检查真实长内容、空态、编辑及错误态，常用桌面宽度、主题和字号；机械费现有精修只作参考，不把其CSS全站覆盖。
- [ ] 检查共享弹窗、输入焦点、金额对齐、间距、操作主次与返回位置的累计影响；修复本批引入的回归，避免无关重设计。
- [ ] 登录页保留现有已认可结构，机械费正式替换仍由其业务票承担；管理员、读屏、移动触摸、实体打印和性能测量未做时逐项写明，不冒充全站合规验收。
- [ ] 按个人工作流统一核验整合范围、必要审查及发现关闭，完成文档与票状态收口；部署和真实业务写入遵守独立授权。
