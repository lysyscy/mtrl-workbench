## 优先处理的发现

### F01 · P1 · 弹窗没有接管键盘焦点

类别：无障碍。位置：`backend/app/web/shell/base.js:414`的共用modal，规则编辑调用在`backend/app/web/shell/actions.js:334`。

复现：进入规则配置→点首行编辑→按一次Tab。弹窗仍在，焦点却移到背景同一行的“删除”按钮。完整树见`rules-modal-tab.ax.txt`；集采子表开启时焦点也仍在背景触发按钮。共用modal未设置dialog语义、初始焦点与背景隔离，关闭时已有焦点归还，值得保留。

影响：键盘用户无法按可见层级操作，可能误操作背景。建议在共用出口补对话框名称/语义、进入焦点、Tab边界与背景不可交互；关闭继续归还触发点，验证嵌套选择器、Esc与重绘。相关WCAG口径：2.4.3焦点顺序、4.1.2名称角色值；本轮没有完整合规测试。建议`$impeccable harden`。

### F02 · P2 · 月度会大表的年月输入被自身内边距挤住

类别：响应布局。位置：`backend/app/web/index.html:192`统一给`.bigc .inp`左内边距28px，`:1095`日期和其他手填格共用；在`m07-meeting.png`可见现存YYYY-MM值只露出开头。

影响：输入实际存在，但用户难以阅读或校对。建议对日期/备注/金额分别安排有效宽度，为“带入”标记预留空间时不覆盖正文；以完整YYYY-MM与最大常见金额、带入态验证，不修改日期内容。建议`$impeccable layout`。

### F03 · P2 · 财务宽表未按内容安排列与动作空间

类别：布局/实现一致性。位置：`backend/app/web/index.html:574`通知书、`:674`流水欠款、`:1308`集采台账；证据m03、m05、m11。

影响：核对同一行需要反复辨认折行名称和横滚找操作。建议分别处理通知书批量区、欠款概览与台账工作区、集采供应商和合计宽度。先保留对象标识与金额可读，再安排辅助列；不能用缩字或全站统一行高解决。建议`$impeccable layout`、`$impeccable typeset`。

### F04 · P2 · 说明、日志与正常标记挤占主任务注意

类别：信息层级。位置：`backend/app/web/index.html:921`接入页、`:1039`三类汇总、`:1194`特殊费用、`:513`看板；证据m02、m07、m09、home。

影响：用户先扫过大量说明/正常项才能找到当前操作或异常。建议按每页任务收敛首屏：当前结果/异常优先、历史与解释按需阅读，独立大表有区段定位；关键后果仍在决策位置。建议`$impeccable distill`、`$impeccable quieter`。

### F05 · P2 · 主题卡缺少可见名称

类别：主题/可识别性。位置：`backend/app/web/shell/legacy.js:92`。源码有aria-label、title、aria-pressed，卡面只有aria-hidden的图案。证据settings。

影响：仅靠颜色不易记住所选主题或再次选择。建议显示名称与选中标记，不重做配色系统，也不误报为“完全没有可访问名称”。建议`$impeccable clarify`。

### F06 · P2 · 未登录与当前登录反馈矛盾

类别：实现一致性。位置：`backend/app/web/index.html:1433`直接显示CUR.name并将非管理员都标成普通用户。证据users。

影响：用户对当前身份和禁用原因产生误解。建议仅在有身份时显示“当前登录”，无身份时如实提示；权限逻辑保持，登录后的管理员与普通用户另验。建议`$impeccable clarify`。此项含状态逻辑，不能当作纯CSS精修混入。

以上共6组发现：P0=0、P1=1、P2=5、P3=0；逐页表中的次要建议并未重复计为独立缺陷。

## 审计建议分组（已由13张正式票细化）

1. 共用弹窗键盘与语义：先做F01，按共用调用面验证，独立于审美调整。
2. 宽表可读性：日期遮挡先修；付款通知书、集采、项目档案和库存按页分别确定列宽/固定列/动作，避免一次全局改表格CSS。
3. 工作区层级：欠款、接入、看板、三类汇总、特殊费用分别减少寻找成本；保留原流程与业务口径。
4. 配置与身份反馈：主题卡名称、未登录反馈、规则与导入容器密度，分清纯视觉和状态逻辑。
5. 最后统一检查数字、间距、焦点、主题与真实长内容的精修收口。

推荐顺序：`$impeccable harden`→`$impeccable layout`→`$impeccable clarify`/`$impeccable quieter`→`$impeccable typeset`→`$impeccable polish`。可以逐项、整批或调整顺序；修后重跑审计并对照本次证据。用户已批准据此重新拆成13张票，具体范围与依赖回ticket-plan.md及正式票仓；旧提案07—12不恢复。
