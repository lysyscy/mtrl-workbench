# 机械费工作区

工作区四页为公司汇总、零租明细、包月明细、当前累计核对。明细保存、确认采用、有效月值是三层；保存草稿不等于确认报送。有效月值复用过程资料六列，下游只读派生，避免出现第二份有效金额。

## 月值与来源

公司汇总直接确认工程公司内租 mech_0、租赁公司内租 mech_1；零租确认 mech_2/4，包月确认 mech_3/5，含税/不含税独立。付款域机械结算仅为零租含税加包月含税，两类内租和不含税不参加欠款结算；大表复用原六列出口。

由明细确认的格在过程资料只读，普通保存/导入/回滚同值略过、异值拒绝。改回手填必须按项目、月、列明确确认，保留原明细和采用依据后才开放；历史本月手填不能仅因非空锁住。确认与切源校验版本，旧请求不能重新接管。

外部 Agent 经机械费归集 skill 整理原报，生成带项目、月份、类别、明细和来源坐标的 JSON；原文件只读。先预览，确认后写明细，再分别确认月值。整份修订比较旧原报、新原报、系统当前值，单方变化保留、双方同值保留、双方异值及拆合行不确定逐项确认；不靠位置/同额去重。预览后并发变化拒绝，失败整批回滚，重复确认不重复累计。首次历史承接不作为日常历史导入入口。

原报、年度参考及其已含月分量、固定 i6、系统有效值分别保存。累计不叠加各月累计，旧月修订只替换最新累计已含分量；例如原月0、年度4850保持两事实，后续确认5000只增加150。具体项目约定不升格为通用金额规则，也不能当作已入账证明。

明细保留原合价/备注/日期文本/车牌/票种及净额缓存。缺数量时改单价不生成零合价；普票净额等含税（含百分比普票），专票按明确税率算，税率未知待补。源金额保精度，项目合计后舍入；待补筛选不能缩小完整项目合计。无需车牌名单只维护一份，可清空/保存；名单外缺牌待补，2026年1–5月原包月未采集车牌不补造，免车牌检查不免其他校验。

## 当前累计与差异

报表关系为含税零租累计＋含税包月累计＋租赁公司内租，对比固定 i6＋i8 班组设备使用累计，工程公司内租不参加；周材当前值按实际来源，不擅造合计。i8 内部以班组设备使用累计对比项目机械消耗结算＋班组机械消耗审批，不含 i6。逐单审批减结算差异独立保留，累计对平不能掩盖它。

核对取各项目最后采用的当前累计，不随报表月截断。来源、时点、周期可查；未知周期保留原键，不从单号/录单日/ID猜月。未审空额、未取得、缺来源与零分别表达。单项目更新先展示原→新，三类不齐保护整组旧值，未返回旧单/项目不当零或删除；采用减少须核范围并给依据，不写 i8。

全量发现包含权限内显示名单外项目及金额不变的单据变化。首次无基线只称首次发现；未处理跨轮保留去重，本轮无需补报须说明，未来新变化再提示。未配档案保留键及事实，映射后才采用。小微按逐单壳下关键词归属，未定单据不能使项目不完整结果被当完整值采用。

待处理收差额、未忽略单据两额差异、未完成事项及金额已有但对比来源未齐项目；首次/变化另列“取数变化”，纯空显示“尚未录入”。差额可按项目/关系手动留底忽略并撤销，不改两边原金额，不自动容差；待处理额＝原差额－忽略额。单据两额独立忽略，两额变化重新提醒。

跟进事项只需项目和一句备注，可保存/完成、查全部与既有依据。事项不改金额、不自动忽略，也不证明跨月约定执行；摘要只供复制，不自动发送。

## 四页导出

按所选项目顺序、报表月及同一已保存/已确认快照生成公司汇总、零租、包月、年度汇总。草稿不混入，缺明细/待补/采用差异如实提示，不补造行。真实金额和原始差额导出，不用待处理/忽略额替代。每个文件冻结，不随后来修订改变。

年度月列从最早有数月展开至报表月，往年月同样保留边框，不用“往年合计”压掉；累计、班组使用、i6、i8与差额各守其口径。合计公式可重算且保存独立计算缓存，缺月/明细不造零。公司汇总开工日期只读取月度会大表对应月有效值/上次带入，缺值留空，不回退原报历史日期、不反写大表。具体模板布局回 [模板导出](../reference/template-export.md)。

显示名单与本次报送名单独立，明确空显示名单有效；金额跳转的临时项目范围不缩小项目完整合计。预览与下载使用同一快照令牌；保存内容变化后旧令牌拒绝下载，重新预览才生成新文件。读取失败、范围/账号变化、台账草稿、写入在途或未知结果均阻止下载，按可靠读回恢复。
