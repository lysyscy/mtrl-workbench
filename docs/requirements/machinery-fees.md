# 机械费工作区

工作区四页为公司汇总、零租明细、包月明细、当前累计核对。零租、包月明细按回车或离格自动保存，不设统一保存或确认汇总步骤；对应月金额复用过程资料六列，下游只读派生。

## 月值与来源

公司汇总直接确认工程公司内租 mech_0、租赁公司内租 mech_1；零租金额行自动汇总到 mech_2/4，包月到 mech_3/5。有一条合法金额即计入，空金额行不参与，明确0是实值；缺设备名、车牌等保留待补提示，不阻止已知金额生效。含税和不含税分别计算，缺税率的净额保持未知，不用0或已知部分冒充完整净额。首次有金额明细即替换该类别旧手填额；过程资料确认手填后，仅补备注、车牌不覆盖手填额，明细金额或税率改变才自动更新对应月额。删除最后一条金额明细或清空其金额时，对应月额清空，之后可手填。付款域机械结算仅为零租含税加包月含税，两类内租和不含税不参加欠款结算；大表复用原六列出口。

过程资料可直接编辑六列金额；同项目同月存在任何已保存机械明细时，不区分零租、包月或当前格类别，金额改变必须展示原金额→新金额并确认后保存，仅有待补字段的明细和已改手填的格也适用。取消不写入，同值不重复确认；没有明细时沿原逐格保存。若该格原由明细产生，确认保存与切为手填在同一事务完成，原明细、金额来源及其他格保持。确认核有效金额和所有类别明细版本，变化后须重读重新确认。其他写入或撤销不得异值覆盖明细金额；历史本月手填不能仅因非空锁住。

用户2026-10-29确认过程机械格清空保存为空，0仍是明确实值；清空沿同一明细确认/版本保护切为手填，保原明细且不恢复旧金额。新单格入口区分空与零，兼容手填接口保原空转0协议，不批量改已有金额。

用户要求录入本批后，机械费归集skill识别、关联、校验原报，直接经业务保存逻辑写数据库并回读。原文件只读，保留项目、月份、类别、稳定明细身份和来源坐标。整份修订比较旧原报、新原报、系统当前值，单方变化保留、双方同值保留、双方异值及拆合行不确定逐项询问；不靠位置/同额去重。版本过期拒绝，失败整批回滚，相同请求不重复记账。

原报、年度参考及其已含月分量、固定 i6、系统有效值分别保存。累计不叠加各月累计，旧月修订只替换最新累计已含分量；例如原月0、年度4850保持两事实，后续有效月值改为5000只增加150。具体项目约定不升格为通用金额规则，也不能当作已入账证明。

明细保留原合价/备注/日期文本/车牌/票种及净额缓存。缺数量时改单价不生成零合价；普票净额等含税（含百分比普票），专票按明确税率算，税率未知待补。源金额保精度，项目合计后舍入；待补筛选不能缩小完整项目合计。无需车牌名单只维护一份，可清空/保存；名单外缺牌待补，2026年1–5月原包月未采集车牌不补造，免车牌检查不免其他校验。

## 当前累计与差异

报表关系为含税零租累计＋含税包月累计＋租赁公司内租，对比固定 i6＋i8 班组设备使用累计，工程公司内租不参加；周材当前值按实际来源，不擅造合计。i8 内部以班组设备使用累计对比项目机械消耗结算＋班组机械消耗审批，不含 i6。逐单审批减结算差异独立保留，累计对平不能掩盖它。

核对取各项目最后采用的当前累计，不随报表月截断。未知周期保留原键，不从单号/录单日/ID猜月。未审空额、未取得、缺来源与零分别表达。单项目更新先展示原→新，三类不齐保护整组旧值，未返回旧单/项目不当零或删除；采用减少须核范围并给依据，不写 i8。

全量发现包含权限内显示名单外项目及金额不变的单据变化。首次无基线只称首次发现；未处理跨轮保留去重，本轮无需补报须说明，未来新变化再提示。未配档案保留键及事实，映射后才采用。小微按逐单壳下关键词归属，未定单据不能使项目不完整结果被当完整值采用。

待处理收差额、未忽略单据两额差异、未完成事项及金额已有但对比来源未齐项目；首次/变化另列“取数变化”，纯空显示“尚未录入”。差额可按项目/关系手动留底忽略并撤销，不改两边原金额，不自动容差；待处理额＝原差额－忽略额。单据两额独立忽略，两额变化重新提醒。

跟进事项只需项目和一句备注，可保存/完成、查全部。事项不改金额、不自动忽略，也不证明跨月约定执行。核对工作台不提供“依据”弹窗或复制核对摘要。

## 四页导出

按所选项目顺序、报表月及同一已保存快照生成公司汇总、零租、包月、年度汇总。未保存输入不混入，不补造明细或金额。报表不再生成或显示“报表待核对”汇总及缺明细、待补、采用差异、历史月份来源提醒；明细页自身的字段校验和当前累计核对工作台保持。公司汇总沿实际有效金额，只有明细/可追溯月份合计与有效额相符时才生成对应跨表公式，不因删除提醒而改变金额。真实金额和原始差额导出，不用待处理/忽略额替代。每个文件冻结，不随后来修订改变。

年度月列从最早有数月展开至报表月，往年月同样保留边框，不用“往年合计”压掉；累计、班组使用、i6、i8与差额各守其口径。合计公式可重算且保存独立计算缓存，缺月/明细不造零。公司汇总开工日期只读取月度会大表对应月有效值/上次带入，缺值留空，不回退原报历史日期、不反写大表。具体模板布局回 [模板导出](../reference/template-export.md)。

“导出台账”选择项目后直接下载一个含上述四表的Excel工作簿。项目控件沿用欠款页两个导出的勾选、全选/全不选及上下排序，按当前账号在本浏览器独立记住选择与顺序；首次使用带入当前显示项目，已记住的空选择保持为空。显示名单与导出名单独立，明确空显示名单有效；金额跳转的临时项目范围不缩小项目完整合计。读取失败、范围/账号变化、台账草稿、写入在途或未知结果均阻止下载，按可靠读回恢复。
