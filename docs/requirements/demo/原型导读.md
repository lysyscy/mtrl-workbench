## 六、术语表（读原型会撞到的名字）

| 名字 | 是什么 |
|---|---|
| `V.<k>` | **视图函数**：返回该页的 HTML 字符串（如 `V.m03()`）。全量重渲染是本站的原型架构。 |
| `BIND.<k>` | **挂载后钩子**：该页 DOM 插入完成后执行（绑控件、算派生值）。 |
| `ACT` | **动作处理器表**：`data-act` 的值 → 处理函数。 |
| `data-act` | **事件委托的把手**：元素上挂它，点击（或 `change`）时由统一处理器分发。 |
| `CHG` | **输入框类动作的名单** —— **新增输入框类动作必须登记进去**，否则 `change` 被静默丢弃。 |
| `ENUMS` | **枚举值域的唯一出口**（值 + 语义色 + 中文显示名）；标签 / 下拉 / 取色三处自动跟随。 |
| `render()` | 全量重渲染（改状态后调它即刷新）。 |
| `go(k)` | 切页（同时清 `pickSet`）。 |
| `SNAP` / `rollback()` | **可变嵌套数据的快照与复位**（交互测试之间要隔离）。 |
| `__X` | 原型向 `_smoke.js` **导出的测试接口**（`globalThis.__X`）—— **新增顶层变量要补进导出，删除要同步删名**。 |
| `sumRowOf` | **表内「合计」行的统一出口**（只算非剔除行 · 随筛选变动 · 排序后仍在表尾）。 |
| `numOf` / `badMoney` / `overCap` | **可编辑金额字段**的解析 / 非法判据 / 上限容差的**统一出口**（不要在字段里手写）。 |
| `projPanel` | **共用的项目选择面板**（多选 / `single:true` 单选）—— **能力由调用点声明**。 |
| `tmBtn` | **共用的时间选择器**（月 / 跨月 / 年 / 全部…模式由调用点声明）。 |
| `applySorts` | 表头点击排序（优先读表的 `data-sort-key`）。 |
| `dispCell` / `pjDisp` | **展示名**的统一出口（全名只留在悬停 `title`）。 |
| `RUNLOG` | **运行记录**（抓取 / 打印）—— 供看板两类提示（只读演示数据）。 |
| `R1`–`R19` | `demo/设计规则-提炼自付款通知书页.md` 里的**交互规则编号**。 |
| `MOD-*` / `REQ-*` / `DEV-*` / `ENT-*` / `API-*` / `ACC-*` | 编号体系：模块 / 需求 / 决策 / 实体 / 接口 / 验收判据（定义处见 `PRD/99-追溯表.md`）。 |

## 七、怎么复核本文件（可执行）

本文件的每个数字都能**从原型重新算出来**（这也是它不容易过期的方式：**发现不一致 ⇒ 以原型为准，并重跑本节命令更新本文件**）。

```bash
# 1) 视图数与各页代码区间（找 V.<视图> 定义行）
grep -n '^V\.[a-z0-9]*=' delivery/demo/材料报表自动化工作台-交互原型.html

# 2) 交互动作名（去重）
grep -o 'data-act="[A-Za-z0-9_]*"' delivery/demo/材料报表自动化工作台-交互原型.html | sort -u

# 3) 代码分区 banner
grep -n '/\* =\{10,\}' delivery/demo/材料报表自动化工作台-交互原型.html

# 4) 表头常量
grep -n 'const [A-Z_]*_THEAD' delivery/demo/材料报表自动化工作台-交互原型.html
```

> **四检**（原型改动的必做动作，见技能 `mtrl-workbench-prototype`）：`delivery/demo/_smoke.js`（业务与交互断言）· `_doccheck.js`（文档事实）· `_links.js`（引用健康）· `_ids.js`（编号可解析）。
