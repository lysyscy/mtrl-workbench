# 导出模板清单（登记表 · 唯一存放处）

> **本表是全部 `.xlsx` 导出模板的登记处**（含 `demo/模板/` 下的、以及素材包 `data/templates/` 下的）—— 登记「模板文件 ↔ 工作表 ↔ 报表名 ↔ 数据来源页面 ↔ `DATA_START` ↔ 列子集 ↔ **模板列名 → 页面列**」。
> ⚠️ **本表不写模板份数** —— 写了就是"带值摘要"，模板一增删就会静默过期（本项目已多次踩）。**份数以盘上实数 + §二 的清单为准，本表即权威、别处不另记计数。**
> **为什么放这里**：实现阶段第一件事就是读它，放在模板旁边最不会被漏；它**不是**"现况文档"，是**绑定真实文件的登记表**。
> **⚠️ 模板一换，本表必须跟着改**（本表是"哪个模板挑了哪些列 / 哪个模板列对应哪个页面列"的**唯一存放处**，没有第二份）。
> **列名与取值口径的唯一主人 = 页面列**（《材料科业务全流程说明书》§7.1）：模板只**引用**列，**不得另行定义**。
> **`DATA_START`（仅路径①）= 标记文字**（**方案 A** · 2026-09-14 定）：实现**读数据区首行那格的文字**定位，**不依赖 Excel 定义名称**（规则口径见《说明书》§7.1）。**模板无需补定义名称。**
> **核对范围**：DATA_START与既有尾块登记沿2026-09-14实测；机械费路径③及其原四页映射于2026-10-19核对，详见§九。

## 四、`DATA_START` 的实测结论（**要紧**）

### 1. ✅ **现行口径 = 只用「标记文字」（方案 A · 2026-09-14 定）**

单元格里那把 `DATA_START` **文字就是锚点** —— 实现直接读**数据区首行那格的文字**定位（口径见《说明书》§7.1「数据区的起点识别」）。**无需补任何定义名称**（理由见 §1b / §1c）。

**坐标（标记文字所在格 · 逐 sheet 实测）**：台账 `辅材` / `机械` / `特殊费用月报表` = **A3** · 过程资料 `汇总表` = **A4** · 焊材气体 `焊材` / `气` = **A2** · 开会大表 `Sheet1` = **A5**。
（登记在这儿只是"给人看的地图"；实现**以文字实读为准**、不抄这些数字。）

### 1b. ⭐⭐ **一个工作簿只能有一个「工作簿级」`DATA_START`** —— 但**方案 A 下不必补定义名称**

⚠️ **实测踩到的真坑**（2026-09-14）。Excel 的**工作簿级**名字**全局唯一** ⇒ 台账（`辅材` / `机械` / `特殊费用月报表` 3 个 sheet）**没法各建一个工作簿级 `DATA_START`**，后建的会覆盖先建的（在名称管理器里直接冲突）。

**✅ 结论（2026-09-14 用户拍板 = 方案 A）**：**实现以「标记文字」定位，不依赖定义名称** ⇒ **6 个 sheet 都不必补定义名称**（口径见《说明书》§7.1「数据区的起点识别」）。这条坑**只作为"为什么不做定义名称"的记录**保留。

### 1c. ⚠️ **为什么不用定义名称：openpyxl 3.1.5 的两个坑**（备查）

**实测行为**（`openpyxl/workbook/defined_name.py` 源码 + 真实模板回读）：

- `wb.defined_names` 是**按「名字」做 key 的扁平字典** ⇒ **同名必然互相覆盖**（`DefinedNameDict.add()` 就是 `self[value.name] = value`）。用 `wb.defined_names.add(...)` 连加 3 个同名，**只剩最后一个**（实测确认）。
- `wb.defined_names` **只暴露「工作簿级」名字**；`localSheetId` 有值的（工作表级）**一个都读不出来**（实测：Excel 生成的文件里 `localSheetId="0"` 的 `Print_Area` 读不到）。

⇒ 若走定义名称，须 `zipfile` + XML 直读 `xl/workbook.xml` 的 `<definedName localSheetId=…>`，按 `localSheetId → wb.sheetnames[i]` 映射。⚠️ `localSheetId` 是**表在 `workbook.xml` 里的出现顺序下标**（不是 `sheetId`），改名/挪表就变 —— 又一个"副本"。**方案 A（标记文字）没有这些问题，故选 A。**

### 4. 其余格式提醒（填数时会咬人）

### 5. ⭐ **合计行与尾部行块 = 按实际数据行数派生**

> **规则口径的唯一主人 =《材料科业务全流程说明书》§7.1**（「数据区的起点识别」+「尾部行块随行数派生」两行）。**本节不复述规则**，只登记**这份模板的实测事实与操作做法**。

**背景**：`DATA_START` 只锚「**数据区起点**」**一个点**，**不携带行数** ⇒ 模板里合计行**死在一个固定行号**上，数据行数一变就错位（⇒ 规则回《说明书》§7.1）。

**实测：只有一份模板的「合计行下面还有东西」** —— **过程资料 · `汇总表`**（**份数从略** —— 写计数会过期；本表只登记"是哪一份"）：

| 模板 / sheet | 合计行 | 下面还有什么 | 处置 |
|---|---|---|---|
| 台账 `辅材` / `机械` | R19（`=SUM(C3:C18)`） | **无**（dim 到 19） | 只改公式区间 |
| 台账 `特殊费用月报表` | —（该 sheet 单月列 · dim 到 6） | **无** | — |
| 焊材气体 `焊材` / `气` | R9（`=SUM(...)`） | **无**（dim 到 9） | 只改公式区间 |
| 开会大表 `Sheet1` | R13（`=SUM(D5:D12)`） | **无**（dim 到 13） | 只改公式区间 |
| **过程资料 `汇总表`** | **R13 = 合计**（`=SUM(C12:G12)`） | **R14 = 固定脚注**「1、材料费用：财务数\*\*元…」＋ `A14:R15` 跨两行合并块 | ⭐ **整块按 offset 下移** |

**⭐ 过程资料特别注意：它是「两段合计」**（不是一段）：
- `R12 = 小计` → `=SUM(C4:C11)`（**数据区求和**）
- `R13 = 合计` → `=SUM(C12:G12)`（**横向小计的求和**）

⇒ 数据行数一变，**这两行都要按数据区实际范围改写**，且「合计」公式要指向**小计那一行**（不是数据区）。**这一步最容易被漏。**

**做法（openpyxl）**：读模板后先把**样板数据区删到只剩数据区首行**（留它当行样式母版）→ 按 n 行复制写入 → 在数据区下方 `ws.insert_rows(m)` 插入所需行 → 按 offset 把尾部行块（含脚注、合并）搬到算好的新行号 → 改写公式区间与合并。⚠️ `ws.insert_rows()` **默认不搬公式与合并区**，须自己按 offset 修补。
