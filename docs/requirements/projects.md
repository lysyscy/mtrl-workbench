# 项目、仓库与身份

项目档案是付款和材料归集的地基。普通项目拥有独立 i8 编号及仓库；小微壳有 i8 编号和全名、没有仓库；具体小微借壳全名及编号、有自己的仓库。全名不唯一，不能用它做写入主键。

## 名称与归属

仓库名唯一，由建档/扶正写入，不能人工改；展示名默认仓库名、可改且不改变归属。项目全名可人工修改并留痕，i8 phid 不可手改。全名只作 i8 匹配媒介；候选显示展示名，旧读取筛选键使用仓库名，真正写入仍按档案 ID。壳不进入有仓库的项目候选。

全名中的“小微”识别词可配置；项目类型展示已有识别/归属结果，当前界面不提供用户修改类型，保留既有历史记录；不含识别词却挂多个仓库时必须人工确认。付款早于仓库时可先建占位档案；材料侧或用户主动同步仓库后按归一化全名桥接扶正。主动同步仅对唯一对应的占位档案原行修改仓库名，保留ID、信息化编号及业务关联；默认占位展示名跟随更新，自定义展示名保留。多仓库、同仓多归属、未建档及已有真实仓库冲突逐项列出，不自动创建或猜配；扶正与成功执行记录同事务提交，失败整批回滚。名单及人工指认已有候选读取/提交实现，复用 mod01_project 与 mod02_i8，不再把它列为未开发。

付款先判断是否壳，再在该壳下按单据名称匹配具体小微关键词，包含已归档小微。关键词允许跨壳重复，匹配不能跨壳；未命中/多命中须人工依据，不把整组共享编号猜给一个小微。人工选择既有小微时，关键词须出现在单据名内；新建须先有壳。

抓取时归属未定行本次跳过，正常行继续，结果列出跳过数量、单据、原因及本月未齐提示，执行记录保留清单。跳过行不写成待指定通知书、不参与统计或付款，不建立永久忽略标记；下次重取重新校验。登录/取数/数据库异常仍报错，正常行写入失败按事务回滚。已有旧单变更按现有规则处理。

## 状态与候选

项目只有在建/归档。归档只改状态并留痕，不改通知书、流水、材料、机械或历史归属。壳下尚有在建小微时拒绝归档壳且不写留痕；最后一个在建小微归档时壳跟随并独立留痕。已归档壳下新增小微须先恢复壳。

项目候选包含归档项，归档后置并标注；默认筛选仍在建。候选折叠归档段须显示已选数量，搜索能找到归档项，全选范围不被可见搜索结果缩小。项目默认排序为归档后置、档案 ord、原顺序；活动大表有独立项目集合与顺序。排序和展示名不做业务留痕。合并/换壳不能从旧设想推导操作授权。

## 账号

权限由后端判定，前端禁用只是提示。账号停用/恢复及转让保留既有权限和历史身份保护，不硬删历史操作者。本人可改自己的密码且保留现有会话，不另建多余账号页；他人账号管理继续按现有角色能力。账号切换时清掉上个身份的数据与草稿。
