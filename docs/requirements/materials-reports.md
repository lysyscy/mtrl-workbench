# 材料、调整、过程资料与报表

库存单据是材料事实来源；调整单在旁路记录修正，过程资料、特殊费用和报表消费同一份有效数据。源数据不能人工改，i8 重抓不覆盖调整单；不能在多个页面各维护一份修正值。

## 库存与调整

库存按核算年月、仓库保存，重复抓取替换同范围的自动来源，不触碰手工行。实际行身份、全名/仓库桥和表头解析回 [i8 契约](../reference/i8-contract.md)。归属不可靠时不给正常项目猜配。

调整单保原值、改后值、操作者、时间及必填备注，提供撤销，相关统计重算。原始表、调整后表和差异表分别可查/导出，差异由调整派生并能定位原行，不新增独立手工差异页。删除前显示实际影响并确认，关联/撤销保护沿当前实现。

## 过程资料与特殊费用

过程资料取当前材料信息；机械六列有效值由 [机械费](machinery-fees.md)持有，不另算第二套。原始和调整后口径可分别报送。汇总、原始、调整与差异的关系须清楚；同一月份/项目的自动输入幂等，失败不留下半批。

特殊费用有自动取数项与手填项，自动项不能以手填覆盖源事实。金额校验按字段含义：普通付款等严格正数；允许清零的字段接受零；历史纠正、过程材料和费用调整中已允许负数的字段继续接收负数，不能为了统一验证禁掉合法调整。

主线保留过程资料与机械报表通用表格导入。先选范围、映射表头、预览及确认，处理过的来源重复提交不重复累计；手动行和已确认机械来源受保护。过程资料说明/合计/空行不作数据，标段行是真数据，合法负数照收。机械明细 JSON 预览录入是另一条合法入口；不能把旧“只留通用导入”扩为禁止它。历史付款和集采 Excel 导入无现行入口。React 独立分支按React425退役通用API、m06_proc与m06_mech_report及其专属写入/回滚编排；保留机械明细JSON预览、修订校验与确认、原有历史快照/批次/来源读取和过程资料查询导出。旧web保持原样，旧导入入口在加载此后端后不可用；主线尚未合流，不能据其旧入口重建。

## 月报与分析

收发结存按仓库/核算月取数，提取与结余各守原含义；历史结余是用户手填，不从未知来源推零。活动大表有自己的项目集合、排序及手填上次值带入，不影响其他页的档案排序；带入值与本月已确认值区分，不能默认已确认。

各报表按下述实际来源装配，不能把它们统一成同一材料数据源；导出行集合以各功能实际所选范围为准，页面筛选不应偷偷改变项目完整合计。模板结构、字段映射、透视/公式缓存及成品格式由 [模板导出](../reference/template-export.md)持有。

实现入口：`mod06_proc`、`mod07_setl`、`mod08_inv`、`mod09_fee`、`report_export`。月末/半年度修正应显式作用到所属月份与记录，不能改源事实或以显示修订冒充实际入账。


## 材料取数与导入优先级

过程资料每项目一份成本台账，通常每月5–10日报工程科，材料列取库存分库位金额，与收发结存无直接取数关系。按物料性质分主辅材（合并主材/辅材）、工具、劳保、周材、临设，未知性质不猜归类。2025-12起入库/出库各五列派生只读；差异修改在库存行的调整单，点差异定位原行并能清除定位。

同项目同月有i8库存时整月材料列优先库存，不逐格补齐或叠加历史导入；原始取原单、调整后叠加调整。i8数据从2025-12起；2025-11及之前源于i6，系统不可取。React过程资料可增加历史月份并逐格直接填写这些历史材料金额，手填值在原始表、调整后表及导出中一致，未手填的格沿用有效历史快照；独立保存手填值，不改导入快照。清空该格保存为空，零和负数合法；可通过操作历史撤销。若该月意外已有库存，拒绝手填并核对来源。保存时核对原显示值，发生冲突须重读并重新输入。下述Excel导入写入规则仅说明未合流主线及既有历史的形成方式，React不再提供该入口：材料/机械分别选本次截止月，空则各取文件内最大有效月；只限制本次输入，不挡已存显示/编辑。先排除不选类别，再验所选金额，改范围使旧预览失效。重新导入替换该项目全部历史导入材料，未包含的旧材料月退出有效快照；机械仅本次范围按列最后成功写入为准，同月标段先加再覆盖，空不写、明确0才清零。异常整批拒绝，失败保原内容，回滚不覆盖后来的手录/重导及明细确认格。

未合流主线的导入候选是档案全量含归档∪有数据项目，过程资料展示候选只需有数据，两处不能合并。机械报表通用导入只读所选月：年度内租/零租/包月映射对应含税列，不读工程公司汇总或覆盖租分公司设备；不含税分别取零租I列/包月O列项目明细，缺失不倒算，缺月份不猜。项目按仓库名、展示名、配置别名精确匹配，未配列出跳过，确认逐项目逐列差异后才覆盖。

## 提取、费用与会议大表的实际来源

焊材/气体提取取库存**原单入库金额**，不取价税合计、出库或人工调整金额。气体资源名称精确白名单（氧气瓶/气表等工具不收）；焊材包含焊丝/焊条/焊锡并排除工具子串，不加单位闸、不收焊接防飞溅液，排除词不能泛用“焊接”误伤真耗材。现行名单/关键词由取数规则配置持有，文档不抄第二份常量表。

提取的“2025-11及之前”是类别×仓库手填历史值，未填空、0合法；合计为该历史值＋所选年12个月，2025年1–11月留空。往年金额另作展示，不重复加入合计；2026起页面隐藏历史列但不改金额和导出年度汇总的保留列。没有读取到不能显示0。

特殊费用按项目维护统一费用项，名称跨月份及年份一致，每个项目内的有效项名唯一；年度表每项一行，列为往年、1至12月、累计。新增先保存费用项，不凭空创建月金额；每项每月最多一条金额，未录留空、真实0显示0，清空只删除该月金额，允许负数。改名作用整项及其全部年月显示，删除整项使其全部年月金额退出统计，可安全撤销恢复；删除前说明往年及其他年份也受影响。往年取早于所选年1月的真实月金额，累计＝往年＋所选年各月，未来年份排除。自动安文费仍按核算月、项目和CBS安文费出库原金额派生，只读，手填项不得占用其名称；往年、累计也只读。迁移保留旧表全部原记录及字段，同项目同名同月记录金额相加生成唯一月金额，不回写旧表。旧月度API继续兼容：金额、删除作用当月记录；名称修改作用统一项；批量按项目、项名、月份更新唯一金额，空格跳过。费用继续随逐月欠款台账的「特殊费用月报表」工作表导出，未增加年度导出。

会议大表焊材/气体累计复用提取合计；外租机械取有效零租含税＋包月含税，设备租赁取有效内租，开工累计按其月值；租分公司设备与两不含税列不参加。合计为外租累计＋设备租赁累计，使用率＝合计/机械测算，产值完成率＝含税产值累计/合同预估价；主材累计取项目内纳入集采合同结算合计，不另造“材料费”列。零分母沿既有出口处理，不补造比率。

大表从在建非壳候选多选，名单和顺序按核算月独立，页面/导出同序。未配置月份继承最近更早已配置月（明确选空也算配置），再无则沿原全局名单基线；原本从未配置时保留全部候选的初始默认。仅查看不写，首次保存名单/顺序、有效手填内容或成功导出时固定当月名单。已固定月保留后来归档的已选项目；继承新月时剔除已归档项目，其他顺序不变，新建项目需手动勾选，不改变既有固定月。旧全局基线不改、不假造历史名单。未录手填格向前找最近录入值并标来源月，改后为本月值，清空回带入，完全无历史空待填；只读带入不写旧月、不参与欠款。手填错下月填对，不造补正记录。报表模板导出后在Excel打印，无页面打印。材料修正由半年度等实际对账驱动，能在i8修的在i8修，否则保差异原因；不恢复独立手工差异页。

过程矩阵机械手填逐格保存，保存/重读保下一格草稿和焦点；从明细切回手填须确认，保当前有效金额。差异定位使用稳定库存行ID并保原筛选，不能按重复单据号定位。库存导出只接受单月，使用该月全项目的真实本地源缓存，页面筛选不缩小源文件范围，无缓存时提示先抓取而不在线补取。

会议大表项目、辅材、机械、产值分别按3/4/7/3列分组；自动取数继续实时派生，分月名单固定不冻结自动金额。
