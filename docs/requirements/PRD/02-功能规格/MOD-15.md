## 三、硬边界（本模块**不做**什么）

| 项 | 依据 |
|---|---|
| ⚠️ **不为系统外干系人设账号**（项目端 / 会计 / 资产处 / 大领导 / 供应商 / 班组一律无账号） | `NG-17` · §1.5.2 |
| ⚠️ **不做「角色 / 权限配置」界面** —— 两人业务权限无区别，配了也没有区别 | §1.5.1 |
| 列设置面板 / 列宽拖动 | `NG-01` · `NG-02` |
| 提醒与督办 | `NG-04` |
| ⚠️ **本页刻意不放大卡片（.kpis 形态）** —— 它不是「域级总览」页 | 交互基准（`R2`） |
