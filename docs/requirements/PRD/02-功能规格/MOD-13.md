## 一、模块定位

| 项 | 内容 |
|---|---|
| 模块 | 跨域能力（全局 · 《说明书》§7）；不设独立说明页与导航，实际导出、删除和共用处理留在所属页面 |
| 模块映射 | 《说明书》附录 F 的 `MOD-13` 行（**这里是页面 / 入口的主列表**） |
| 对应需求 | `REQ-R1`（列表页导出 Excel）· `REQ-R2`（删除二次确认 + 列影响范围）· `REQ-R4`（附件双 tab，**一期不做**）· `REQ-R5`（入库附件批量审查，**二期**） |
| 关键口径 | 附录 F 本行**未挂** `DEV-*`（写 `—`）；约束落在 §9.4（数据删除策略）与 §7.x 各节 |
| 交互基准 | 原型各列表页的「导出」入口与删除确认框；页面与交互规则 = `demo/设计规则-提炼自付款通知书页.md`；**找页面 / 找动作 → `demo/原型导读.md`（§三 该页索引）** |

## 三、硬边界（本模块**不做**什么）

| 项 | 依据 |
|---|---|
| **提醒与督办**（飞书推送 / 系统内提醒 / 时间节点总表）—— 整条取消 | `NG-04` · §7.4 |
| **附件双 tab**（一期不做，延后评估） | `NG-07` · §7.3 |
| **入库附件批量审查 + 导出 zip + 月初提醒**（二期） | `NG-08` · §7.3 |
| 列设置面板 / 列宽拖动 | `NG-01` · `NG-02` |
| ⚠️ **源数据（i8 行）永不被人工修改** —— 导出与删除都必须遵守 | §9.3 · §9.8.1 |
| ⚠️ **不做「全局核算期」** —— 年月一律按各表自己的默认年月（主人 = §9.2） | §9.2 · §6（日期选择器组件说明） |

## 四、验收

**本模块各条用例的判据 ＋ 覆盖点**都见 `PRD/验收/验收基线.json`（**「覆盖点」的唯一主人 = 该文件里每条用例的 `cover`** —— 本处**不复述**：那批副本曾**实测漂移**，2026-09-15 审计 `E4`）：

- `ACC-X-EXP-001` —— 列表页导出 Excel（**导出内容须与当前筛选一致这一条判据尚未有断言** —— 见基线 **`_pending_assertions`**（唯一登记处）的 **A 档**）
- `ACC-X-DEL-001` —— 删除二次确认 + 列影响范围
- `ACC-X-ATT-001` / `ACC-X-ATT-002` —— **不建用例**（前者 Non-goals、后者二期）
- `ACC-USR-MGMT-001` —— 账号与权限的实际能力在 `MOD-15`，判据在其中覆盖
- `ACC-I8-TIME-001` —— 时间选择统一为核算年月（**本模块是被约束方之一**）
- `ACC-UI-THEME-001` —— 外观主题 / 多套配色自选（**用户口述新增 2026-09-16**；判据钉**机制**、不钉观感 —— 颜色好不好看只能人眼判）

> ⚠️ **刻意不用表格**：见 `PRD/02-功能规格/MOD-03.md` §四 的说明（`ACC-*` 定义处唯一）。
