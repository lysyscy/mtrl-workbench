# 付款、流水与欠款

审批金额和审批状态来自 i8；实际已付金额来自有效付款流水；统计结算/统计付款是欠款用的人工旁路。三种事实分别保存。结算性质为冲账，实际付款方式为现汇、承兑、供应链、其他，其他须备注。

## 通知书与实际付款

按既有分类、剔除/恢复和撤单保护处理通知书。源字段重抓可更新，手改分类和统计覆盖保留；撤单保留有牵涉事实，不静默丢账。有牵涉撤单可仍参与统计，不能付款。恢复仅作用勾选行，包含人工及规则剔除行。

付款采用勾选后批量操作，可逐行移出且保留剩余草稿。审批未批、本次金额非正、已剔除、i8 撤单或集采未关联合同均不可付；前端提前显示原因，后端提交时整批重算，任何一行失败都不生成流水。request_id 防重复提交，每次付款各记独立流水。本批备注写每条流水，不覆盖通知书备注。

窗口默认方式优先级：本次手改 → 已确认拟付款方式 → 关联合同约定 → 现汇。拟方式、合同默认、流水实际方式是不同事实；刷新提醒不能覆盖手改草稿。集采账期只提醒，按 [集采业务](central-procurement.md)及[共享契约](../reference/jc-payment-contract.md)取得日期依据。

付款状态只有已付清/未付清，按有效流水合计是否达到审批金额判定；统计人工覆盖不参与状态。撤销按一条流水、必填原因，只回退该条有效流水及相关合同合计；不改 i8，也不覆盖手改统计值。未人工覆盖的统计付款随付款/撤销统一重算为有效流水合计。

## 统计与历史台账

统计结算默认审批金额，统计付款默认有效流水合计。人工编辑二者均不超过审批金额，超额拒绝并保原值；记录前后值、操作者、时间。清空人工覆盖即恢复跟随。真实历史流水超审批仍照实保留并提醒，不能用手改上限截断实际事实。付款统计只计有效实际流水，按付款日期、周一至周日或自然月归桶，人工统计覆盖不改实际支出。

辅材欠款为历史行及正常月统计结算减统计付款；机械结算取有效月值外租零租含税加外租包月含税，付款从所属月份取；集采欠款归合同台账。三类按归属汇总，零欠款项目可隐藏，负数保留。

2025-11及以前辅材可新增多条历史行，同月可多行、金额正负可录；已有历史通知书月份编辑保存显示额，不再叠加原通知书。机械历史只编辑付款，结算始终引用机械有效值，不把已知累计付款自动分摊到未知月。2025-12起正常月继续通知书统计，不由历史编辑截断。

历史编辑不生成实际流水；可删除自己的辅材历史行并按现有能力撤销。按版本拒绝并发覆盖。离格即发保存，保存/读回不打断下一格草稿与焦点，完成编辑后刷新合计。同项目保存保留两侧滚动；切项目才各自定位底部。未填单据日期的有效付款独立列出并只计一次，有来源零值仍保留；完全无来源显示空态。页面可隐藏双零无备注空月，导出保持原逐月范围。

## 原表核对与打印

付款计划由原始 Excel 和 `skills/payment-plan-audit` 核对。系统不提供旧计划页、强制通过/再次匹配或写入入口，旧表数据不因此删除。10号截止和计划外付款由用户把握，不作系统拦截；拟计划不等于实际付款。主线原表核对的合同方式扩展按[分支接口范围](../reference/jc-payment-contract.md#主线原表核对与备注迁移)核实；其业务意图是合同方式冲突/未填的行暂不回写、正常行继续；用户修表或明确例外确认后重新预览，按原指纹、金额、归属与防过期保护回写。

本分支复制输入仅识别完整 FKTZS 标准号，不从混杂文本截局部号；取消的独立定位工具不恢复。已撤单且有支付/合同牵涉时，提示先撤销付款/解绑，相关文字完整可读；该提示不改变准入。

复制完整单据号只帮助勾选，不表示打印或付款。完整列表匹配，重号不猜，已付清可补打但付款仍核验；无有效命中/读取失败保留原勾选。打印沿 i8 版式，投递接收与纸面完成分别判断。已接受的签名节点名称未归一化、模板没有对应槽位的情况仍按实际版式处理，不声称签名齐全。源码定位为 mod03_notice、mod05_flow；i8 细节回 [契约](../reference/i8-contract.md)。

## 导出项目偏好

逐月台账与总欠款导出的项目集合、顺序按账号及用途分别自动记住；重新打开/刷新恢复，清空也保留。失效项目移除且其余顺序保持，新项目须手动加入。关闭弹窗不撤销已记偏好，也不改变普通筛选/勾选/未保存输入的临时内存规则。偏好保存在本机浏览器，清数据、换浏览器或设备后须重新选择。
