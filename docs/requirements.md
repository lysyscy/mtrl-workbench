## 跨主题原则

金额单位元，业务出口保留两位、ROUND_HALF_UP，使用 Decimal；归一到两位后容差为零。原报明细中更高精度先保留，按所属业务合计后舍入。未知、未取得、空白与数值零各有含义，不能为显示齐整填零。

写入按内部 ID 定位，名称只用于受控读取/匹配，多命中不猜。源事实与人工判断分别保存：源字段跟随已核 i8 新值；人工覆盖按所属业务保护，不把保护扩大为所有字段永不更新。

删除与撤销按各域真实能力处理，动作前显示影响范围，相关统计同步重算。通知书、付款流水、账号与调整单不能用通用“全局删除”规则绕过各自保护。账号历史身份须可追溯。重复请求不得重复记账；事务失败不留半批。

对外日期区间为 start_date/end_date ISO 闭区间，报表按核算年月；通知书结算按单据日期，实际付款按付款日期。页面默认不改变用户所选范围；无全局核算期。默认通知书查询全部时间，通知书抓取/流水当月，月度材料报表上月，均按北京时间。

导出行集合和排序按各功能的当前筛选与既有合同，不用网页虚拟窗口代替全量选集。业务、接口、运行加载和用户现场验收分别核实。React 与 Mini App 的范围回各自[活动规格](status.md)，早期设想不自动变成未来任务。
