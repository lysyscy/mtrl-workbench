# 模板结构、字段映射与导出

用户成品模板是生成基底，不能只当形态样例或只修改 i8 源文件。实际运行文件、声明及 SHA 以 backend/app/report_export/resources.py 和资产字节为准；模板、字体与授权保留，本文不抄第二份当前哈希表。

## 生成方式与陷阱

模板填充走 report_export/tpl_fill：DATA_START 是单元格标记文字，不依赖 Excel 定义名称。未登记对应列报错不猜；标题项目名/年月替换样例。数据区之外的小计、合计、合并及脚注按实际行数整体移位，不能只 insert_rows 后以为公式/合并会自动移动。模板样例值不作业务默认。

收发结存与库存透视成品保留用户成品 xlsx 的 ZIP 结构，注入数据 sheet/sharedStrings、pivotCacheDefinition/Records 和 pivotTable；单纯 refreshOnLoad 不能保证打开时显示区正确。核缓存 item 索引与数据一致，sharedItems 计数、cacheFields 与引用范围同步，清除旧行残影；openpyxl 对某些透视模板读写会破坏结构，不对整本盲目 roundtrip。源数据来自同一实际筛选/业务取数，不能拿旧 i8 文件替代当前输出。

公式不由 openpyxl 计算：一般业务值直接写数值；过程资料及机械费合计按已确认规则保可重算公式，并写独立算得的结果缓存。过程资料小计求实际数据行，合计引用小计；四段合并C:G、H:L、M:P、Q:R及机械区/脚注完整移位，Excel出口零值留空，包括小计/合计零，不改变页面/库/明确0输入含义。模板结构改变或升级引擎时核实际成品及缓存，不以文件存在或能生成证明打开正确。

## 机械原四页

输出工程公司汇总、零租、包月、年度汇总；按已保存/已确认快照、项目顺序和月份生成，与网页预览同源。汇总累计表头合并E4:I4、当月J4:N4，零租/包月保项目分段、含税与净额合计，包月O列“不含税价”。租赁日期文本、原备注及车牌不改写。年度取消“往年合计”，从最早有数月逐月展开，末尾累计/班组使用/i6/i8/差额/消耗结算按原布局；i8右侧合计差额为累计减总班组使用。缺明细/月不造零，不改已采用累计，文件冻结后不受后续修订影响。业务含义见 [机械费](../requirements/machinery-fees.md)。

## 欠款导出的范围与月份

逐月台账单项目工作簿含辅材、机械和特殊费用月报表三张工作表，多项目按确认顺序逐项目成品打ZIP；报告月默认北京时间上月，用户所选截止月仍决定实际范围。总欠款按确认项目顺序读取实时欠款，无欠款项目不出行；它与逐月台账使用独立项目偏好。
