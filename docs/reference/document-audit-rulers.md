# 文档检查结果的读法

> 读者：正在整理资料的agent。回答：如何理解已选择检查的结果。何时读：对检查结果有疑问时。
> 选择与执行范围只回 docs/agents/workflow.md；按实际风险显式选择现有工具，定义回各脚本头部，阈值回docs/reference/thresholds.md。

| 结果 | 处置 |
|---|---|
| 相关红档或非零退出 | 对应机器检查未通过；失败归因、是否阻塞与复验按个人implement-solo-spec“验证与失败处理”和docs/agents/workflow.md执行。 |
| 无关红档 | 保留实际非零证据；相关性及交付处置回上述主人，本表不再另定失败流程。 |
| 黄档 | 线索；按当前任务判断用途与实际后果，不因篇幅、预算或历史形式自动扩大核验。 |
| 已豁免 | 需要时核对用途，不能用于藏匿当前未解决问题。 |

普通说明/索引通常核对引用、字节与结构；真实机器输入补使用者检查。仓外资料变化按实际触达选择引用/契约保护，原型未改不附带原型整体验收。改检查机制才运行对应隔离自证。
读取整行汇总和退出码；取完整输出或末尾，避免掐断进程。当前通过结果以实际执行证据为准，不以历史固定条数或旧黄档数量作验收。
