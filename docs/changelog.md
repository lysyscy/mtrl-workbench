# changelog · 使用者可感知的变更记录

> **读者**：用户 ＋ Agent｜**回答**：「哪个版本改了什么」（git log 答不了"使用视角"）
> **何时读**：部署 / 升级后｜**状态**：2026-09-22 建（补记近期节点；更早的看 git log ＋ journal）
> 格式：`YYYY-MM-DD ＋ 变化 ＋ 关联 TAIL/版本`。⛔ 只记**使用可感知**的变化；纯内部重构不记。

## 2026-09-29

- **月度会大表：往右填表不再丢行身份**（`TAIL-175`）：表头与数据行的「下标区」（序号 ＋ 项目名称）固定不滚走；
  20 列横表往右填 6 个手填列时，能一眼看出在给哪个项目填。
- **月度会大表 0 行时给空态**（`TAIL-174`）：不再是一张只剩三级表头的大空表，而是「为什么空 ＋ 下一步」。
- **集采台账：往右填表不再丢行身份**（`TAIL-180`）：勾选框 / 序号 / 合同日期 / 材料名固定；
  4 个可编辑列（付款方式 / 备注 / 存档号 / 寄回日期）在最右，横滚时行身份留在视野里。
- **集采台账那枚「抓取采购合同信息」写清了后果**（`TAIL-181`）：点之前就知道它会登录 i8、**可能顶掉该账号的在线会话**
  （同事正在用 i8 时要先择时）—— 此前它一个字提示都没有。
- **「导出」页卡头只留真入口**（`TAIL-185`）：那枚点了必然空转的朴素导出已撤下（同卡的「导出（含数据透视表）」是真下载）。
- **启动失败的提示条不再盖住页首**（`TAIL-182`）：原来它压在最上层，页首的卡头按钮**点不着**；现在它进正常布局、把内容往下推。
- **`m01` 的「删除」不再假装能删**（`TAIL-177`）：点「确认删除」此前只说一句「尚未接通后端」；现在按钮置灰、
  原因写在弹窗里看得见的地方。`m03` / `m05` 的同类说法一并订正（`TAIL-179`），并修掉一处「删了还能恢复」的错说法（其实**真删**）。
- **两处状态色改回普通说明**（`TAIL-184` / `TAIL-186`）：`m08` 那句「系统会怎么表现」不再用成功绿、`m14` 那句口径说明不再用危险红
  （红只给危险 / 错、绿只给「这一步已经做完」）。

## 2026-09-28

- **「导出与删除」页（原内部叫法「跨域能力」）整页改成用户视角**（`TAIL-124` / `TAIL-131`）：卡头从需求编号（`R1`/`R2`/`R4`/`R15`）改成**人话**（导出 / 删除 / 附件）；一期范围与非目标那张"给产品看的"清单**移出界面**（留在交付面）；三枚只弹假数据的"演示"按钮删除。
- **导入页 / 看板 / 设置页的说明文字不再满屏星号**：`**加粗**` 一律按格式渲染（此前原样上屏，用户看到的是 `**这样**`）。

## 2026-09-27

- **界面大小四档可调**（`TAIL-129`）：字号与间距一起缩放，**点完即时生效、不刷新页面**；按用户记住（换账号各是各的）。
- **报错一律「人话 ＋ 下一步」**（`TAIL-117` 批次 1）：不再出现 `HTTP 500`、`Failed to fetch`、`Error:` 这类原文；服务没起 / 断网也照此。
- **取数没回来不再画成"这页没数据"**（批次 6）：新增「正在读取…」与「没能取到 ＋ 重试」两个状态页，**点重试真能恢复**（只重拉本页那几路）。
- **开发代号撤出可见文案**（批次 2）：按钮与标题上的 `API-05` · `R1` · `TAIL-xx` 这类内部编号去掉（排障线索转悬停）；顶栏/侧栏**只给"还没接通"的页**标注。
- **长说明压短或折叠**（批次 5）：默认展开的说明块 ≤ 200 字，细则折进 `<details>`（要看才展开）。
- **金额一律带「元」＋「截至 今天」**（批次 4）：去掉「容差 0」「Σ」这类验收术语。
- **同状态一套视觉语言**（批次 0 / 3）：绿色只表示"**这一步已经做完**"，黄色只表示"**风险 / 禁止项**"；共订正 14 处错位。

## 2026-09-22

- **导入升级（`TAIL-69` Phase 1+2）**：付款计划 Excel 导入改为「**解析预览 → 确认落库**」两步——预览先看行数与项目匹配盘点（未匹配/重名逐行列出），确认才写库；同批建立统一导入底座 `import_kit`（m05/m06 读表共用）。
- **「库存单据手动导入」入口下线**（`TAIL-70` · 用户裁定）：库存数据一律走 i8 抓取；i8 不可用时显式报错待人处理。
- **m07 收发结存抓取失败提示更诚实**：不再提示不存在的"手动导入"通道，改为显式报错＋请稍后重试。
- **导出下载统一**（`TAIL-67`）：全站导出走同一 `dlExport` 通道（错误分类/文件名一个口径）。
- **虚拟滚动全局化**（`TAIL-66`）：所有大表页 ≥400 行自动启用；输入框聚焦时滚动不丢焦点。

## 2026-09-21

- **服务化（D19）**：程序由计划任务改为 NSSM Windows 服务 `mtrl-workbench-server`（开机自启、崩溃自重启）；Playwright 浏览器迁至服务可用路径（修「只导出 PDF」失败）。
- **看板接真数据**＋四个暂留件（系统设置/历史付款导入/过程资料导入）收口进壳；旧服务端渲染页全量下线（`TAIL-27`）。
- **用户管理**上线（账号/改密/停启用/软删/主题持久化）。

## 2026-09-20

- 集采台账域全量落地（抓合同/台账导入/导出）；差异登记页取消，差异载体=调整单。
