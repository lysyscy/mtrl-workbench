## 定案内容

1. **四步固定骨架**：`① 选文件与来源 → ② 列映射（核心）→ ③ 预览校验（不写库）→ ④ 确认落库`。
2. **系统只出"建议"**：每列给 `建议字段 ＋ 置信度 ＋ 依据`（归一化相等 / 包含词命中 / token 交集 / 类型画像交叉验证）。
   三档：`≥0.9 自动` · `0.7~0.9 预选但标"需确认"` · `<0.7 不预选`（⛔ 不猜，留空给人选）。
3. **必填未映射 ⇒ 下一步禁用**（显式卡住；⛔ 不用默认值糊过去）。
4. **忽略列原样保留**（进"原始列"，预览可见列名）；**解析失败保留原值并报行号**。
5. **记忆**：表头指纹（归一化表头序列 sha1）→ 映射；来源标识兜底；指纹 Jaccard **<0.6 不用记忆**。
6. ⚠️ **AI 只作可选建议层**（**本条已被 `D24` 修订**，2026-09-22 用户问「本地的可以引用吗」之后）——
   默认**关**（`IMPORT_AI=off`）、只在确定性引擎认不出的列上出场、建议一律进「需你确认」档、⛔ **永不自动落库**；
   实现走**本地模型**（Ollama · 不花钱 · 数据不出机器）。⚠️ 仍**不做**模糊相似度打分阈值（那才是纯歧义源，`D24` 表里 `D` 行同样否决）。
7. **域知识留域内**：字段/必填/别名/幂等键/保护/批次 = 域 `SPEC`；底座只做通用事（⛔ 不做上帝件）。
