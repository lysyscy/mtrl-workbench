# TAIL-498: 同一设备在三张台账里怎么对应

**Wayfinder 标签** wayfinder:grilling

- [x] 确认账面行、账实差异备注和设备去向的维护口径

## Question

财务账面行、实体设备和月租明细各以什么为身份？遇到一账对多台、只见于财务账或租赁表、按批记录但未识别单台、同型号同价可能重名时，何时可以建立关联，何时保留待查？

以南靖财务账面 15 台逆变焊机、实物 4 台二保焊机的双向备注为例。再用国风不在流动资产账但计租的设备、焦作佰利租赁独有小客车验证。确认报表合并的前提和无法确认单台时的处理。

证据在工作目录以外，相关原表此前已只读核过。南靖见分布台账「工机具基础信息」56–59 行与盘点表在用工具 75 行；国风见「调拨记录」282–286 行与「分公司9月份」68–70 行；佰利见「分公司9月份」4 行。
