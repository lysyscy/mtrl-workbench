## §〇 操作分支与完成回执

服务报障先走只读调查：`powershell -NoProfile -ExecutionPolicy Bypass -File ops/server_ctl.ps1 -Action status`；再按症状选`log`、`port`、`pg`。这些分支查询服务/端口/日志或GET `/app`，不启停服务、不写库；结束条件是已定位服务状态、占用进程及探活结果，仍未知则据日志继续调查。

| 分支 | 前提与权限 | 改变什么 | 完成回执与边界 |
|---|---|---|---|
| start / stop / restart | 管理员；已有NSSM服务 | 服务与运行进程 | 查status确认状态/新PID与探活；命令发出不等于新行为已验证 |
| pack | 先核`ops/pack.ps1`参数与输入；`-DryRun`不产包，但仍执行0a影响核验 | 非DryRun会产包；WithDump会读取现状库；DryRun也可能写检查回执 | 清单及校验和只证明包内容；不证明能从真实备份恢复 |
| deploy_restore | 未来重装目标、管理员、环境依赖/包/口令齐全；先读脚本分支 | 仓文件、venv、库/迁移、服务；asis的pg_restore含`--clean --if-exists` | selfcheck逐项通过与探活证明安装层；退出0可能含跳过，须看明细。真实恢复须另取隔离空库证据。生产库不作此演练靶 |
| 初始化四入口 | 另有真实数据动作授权和样本 | 确认导入与抓取会写业务库；抓取会登录i8 | 预览、批号、拒绝路径及实际写入核对，不能只以“有行写入”为成功 |

**仍待核的脚本风险（TAIL-223）**：deploy_restore第4步缺仓根`.env`仅提示后继续；Run返回子进程退出码，但调用方将其丢弃，末尾输出不证明各步成功。DryRun跳过Run内子进程及部分写入，新仓分支仍可能创建父目录，不能称全程只读，也不证明实际成功。建角色/配置顺序与可重跑性尚未证明。本轮只校正注释和输出提示（配置主人为仓根`.env`、现行交付面不依赖WPS同步、自检不等于恢复），未修上述执行机制。

## §一 落地五步（目标机 · 管理员窗口）

```powershell
# 0) 把整包拷到目标机（如 D:\deliver\mtrl-20260929）—— 拷完先校校验和（脚本会做）
# 1) 落：仓 + 非 git 件（记忆/nssm.exe/产物/壳基线）+ 交付面快照（第 2b 步只报"怎么用"）+ venv + 依赖 + 库 + 服务 + 探活
powershell -ExecutionPolicy Bypass -File D:\dev\mtrl-workbench\ops\deploy_restore.ps1 -Pack D:\deliver\mtrl-20260929 -Mode empty
# 2) 自检（只证明安装层；包内face为说明书/基线快照，完整验收仍读当前交付面真源）
powershell -ExecutionPolicy Bypass -File D:\dev\mtrl-workbench\ops\selfcheck.ps1
# 1b) （仅诊断快照）显式选包内验收基线；它不替代当前交付面真源：
# powershell -ExecutionPolicy Bypass -File D:\dev\mtrl-workbench\ops\deploy_restore.ps1 -Pack <包目录> -WriteBaseline
# 3) 打开 http://127.0.0.1:8000/app 看一眼（看板是默认落地页）
# 4) 走四个初始化入口各一小段（§三）—— 这一步过了，才算 M8 ①
```

- **`-Mode empty`（新机空库路线）**：建库（`ops/init_db.sql`）＋ `alembic upgrade head`；各步实际成功、安装自检及相关使用验证成立才可用。已有真实历史须另确认备份迁移方案，不默认靠四入口重录替代恢复。
- `-Mode asis`：灌包里那份**本机现状 dump** ⇒ ⚠️ 只用于**复现问题 / 对照**，⛔ 别当生产库起点（测试数据进去后清不干净）。

## §二 落地前后**要改的几项**（⛔ 不得把真口令带进包；现有机制缺口见下）

**产包未核实的敏感输入缺口**：pack会原样复制工作区`ops/init_db.sql`到包，当前SQL含本机实值；文件名敏感扫描不检查SQL内容，不能由“.env不进包/0命中”推定包无口令。正式产包前须先有经授权的不含实值的建库输入及校验方案，未满足不执行产包。本轮不读取/输出口令、不改SQL或产包机制，也未生成包；该风险保持未修，不能等到目标机再换口令才算安全。
