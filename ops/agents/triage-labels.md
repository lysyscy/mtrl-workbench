# 分诊标签（票的 `状态` 行用词）

> **读者**：开票 / 领票的 agent｜**回答**：票的 `状态` 行能用哪些词、每个词什么意思
> **何时读**：写票的 `状态` 行时｜⛔ 本页不新增口径（票的纪律见 `issue-tracker.md`）

五个规范角色**沿用默认字符串**（⛔ 不改名 —— 改名会让"按名字找票"的脚本与判据一起漂）：

| 角色 | 本仓 `状态` 行里的字符串 | 什么意思 |
|---|---|---|
| 待分诊 | `needs-triage` | 还没定要不要做（推测性候选放这儿，⚠️ 先量再定） |
| 缺信息 | `needs-info` | 卡在缺信息（等用户一句话 / 等真数据） |
| 可交给 agent | `ready-for-agent` | **待做**、已说清、agent 可以直接领 |
| 要人来做 | `ready-for-human` | 我做不到的（真机 / 拍板 / 到现场） |
| 不做 | `wontfix` | 决定不做 —— ⚠️ 必须写一句"为什么不做" |

**本仓另加两个（不属五角色，但票要用）**：`claimed`（**在办**：领了先标它）· `done`（**已销号**）。

⚠️ **与旧口径的对应**：本仓尾巴台账原来的"**待做**"= `ready-for-agent`；"**已销号**"= `done`。**阶段 / 时机**那一栏是**另一件事**（受控词 `M0`–`M8` / 立刻 / 持续 / 随时），**⛔ 别和状态混**。
