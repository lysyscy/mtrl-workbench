## 一之五、**配置主人表**（改了哪一项 ⇒ 在哪生效 ⇒ 要不要重启 · ⭐ 2026-09-29 立 · `TAIL-192`-②）

> **为什么有这一段**：同一个配置项**两处存** —— 页面「设置」写**库**、文件里是 `.env` ⇒ 最常见的误解是
