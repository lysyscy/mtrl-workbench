## 一、工程坑（写法级 · 都是实测踩出来的）

### 1.1 环境与配置

1. **pip 配置须纯 ASCII** —— venv 级的 pip 配置文件（`pip.ini`）含中文注释会触发 `Configuration file contains invalid cp936 characters`，pip 会判**整份配置失效**（Windows 以 cp936 读配置文件）。同理 `alembic.ini` 须 ASCII。
2. **路径写法**：Windows 原生程序（如 `initdb` / `pg_ctl` / `python`）**不认 MSYS 风格路径**，必须写 Windows 原生盘符路径。
3. **`.env` 放项目根**，由配置模块加载；**必须进 `.gitignore`**。
4. **依赖源固定**：用 venv 级 `pip.ini`（site 级，优先级**高于** user/global）把 index 钉到官方源 —— 本机 user 级是第三方镜像，不钉就会走镜像。⚠️ 代价：官方源在国内**很慢**（实测装 76 包 **14 分 32 秒**）。

### 1.2 数据库与迁移

5. **schema 变更唯一入口 = 迁移工具**（autogenerate → upgrade）；**禁止**用「建表 API」改既有库（它仅用于测试建库）。基线 + 增量；迁移一致性校验须输出"无待执行变更"。
6. **索引要 sargable**：欠款 / 统计查询的月份过滤一律用**单据日期闭区间**，而非 `substr` —— 否则复合索引失效；**归月展示**仍可用 `substr`（于 SELECT/GROUP BY）。
7. **导入幂等** = 「删除本范围旧行 → 按唯一键 UPSERT」。
8. **软删除**：整型 `deleted` 标记已被时间戳取代；`voided` 保留为**业务撤销**标记（两者语义不同，别混）。

### 1.3 并发与金额

9. ⭐ **付款并发控制选型**：付款主流程用**数据库行锁**（`SELECT … FOR UPDATE`），**不是** version 乐观锁 —— 在多笔并发付款 / 撤销下用行锁**串行化**「读余额 → 校验 → 写流水 → 重算」临界区，**避免重试风暴**；乐观锁只用于「改分类」等**低频冲突**场景（返回 409 提示前端重试）。
   ⇒ ⚠️ **这条是选 PostgreSQL 的关键理由**（SQLite 无行锁）。
10. **乐观锁范围**：**仅金额相关表**继承乐观锁 mixin；非金额表（如项目档案）**不**继承。
11. **快照精度**：软删除快照里的金额必须保留**原始精度**（元、2 位小数），**禁止格式化 / 截断 / 浮点转换**（快照要能反向还原）。

### 1.4 测试

12. **测试固定 PostgreSQL**：PG 不可用时测试基座必须**显式失败**，**禁止静默回退 SQLite**（否则"测试通过"等于造假）。
13. **测试隔离** = 「**外层事务 ＋ SAVEPOINT**」，用例内 `commit()` 只释放保存点、结束整体回滚。
    ⚠️ **写路径 API 测试必须复用该会话**（覆盖依赖注入），否则**路由内的 `commit()` 会写进真实库**。
14. **测试库与开发库物理隔离** ＋ **解析到开发库即熔断**。

### 1.5 应用与框架

15. **导入根 = backend 目录本身**（写 `from core.xxx import …`），**不是** `backend.core`；靠测试配置里的 `pythonpath` 与 conftest 保证。
16. **中间件顺序**：IP 白名单在**内**、`request_id` 居**中**、CORS 最**外**（预检放行）。
17. **单文件行数门禁**：源码目标 ≤ **400** 行、硬上限 **600** 行（`>400` 须登记拆分计划、`>600` 禁止合入）；**文档类不适用**。
    ⇒ 实践：导入入口只做门面，实现拆子包。
18. **FastAPI 0.141 的 `include_router` 是惰性解析** ⇒ 构造期 `app.routes` 看不到业务路由**属正常**，实际请求可命中（别误判成"路由没挂上"）。
19. **文件系统安全时间戳**：删除备份的文件名**不能用含 `:` 的 ISO 串**（Windows 非法）。
20. **日志脱敏口径**：**仅**脱敏凭据类字段（password / token / cookie / secret / authorization → `***`）；**业务数据（金额 / 供应商 / 项目名）保留** —— 二者不冲突。
21. **日志文件权限**：仅运行账户可读写；**保留 ≤ 30 天**。

## 二、工程底线（原「红线」**编号已废、含义留用**）

> ⚠️ 原文档里这些是**命名式**条目（**没有编号**）；「红线 N」是后来各文件**自己起的编号**且**互相冲突** ⇒ **只保留含义**。

| 类别 | 底线 |
|---|---|
| 安全 | **服务绑定**：只绑 `127.0.0.1`，禁 `0.0.0.0`；局域网经**反向代理 ＋ IP 白名单** |
| 安全 | **数据库访问**：强口令，仅监听回环，客户端认证配置禁一切远程 |
| 安全 | **凭据管理**：口令 / 密钥 / 连接串只来自环境变量或 `.env`，**绝对禁止硬编码**；凭据扫描须**逐 blob 全量**（不采信目录规则 / 抽样），且**递归进归档**（zip-in-zip） |
| 备份 | **校验和**：备份须生成 SHA256，恢复前校验，**禁止"静默失败"式备份** |
| 备份 | **存储隔离**：备份存**与数据目录不同的物理磁盘** |
| 备份 | **崩溃自恢复**：数据库启用 WAL 归档 ＋ 自动检查点，异常关闭后能自恢复 |
| 依赖 | **依赖来源**：只来自 **PyPI 官方源**、月下载量 ≥ 10,000；禁 GitHub 直装 / 私有源 / 预发布（`--pre`）/ 小众个人库<br>⚠️ **2026-09-15 本工程按 D10 故意偏离**（用户裁定）：**改走国内镜像**（阿里云 `https://mirrors.aliyun.com/pypi/simple/`，备选清华 TUNA），配套三条加固 = 镜像钉死不回退 · `requirements` **全 `==` 精确锁版本 + 哈希锁** · 新增依赖跑 **`pip-audit`** 出审计报告入库。「月下载量 ≥ 10,000」「禁预发布 / 禁私有源」**仍然适用** |
| 依赖 | **安全扫描**：仓库根须含依赖审计报告；每次新增依赖前必须扫；**CVE 高危禁止引入** |
| 数据 | **软删除过滤**：所有统计类 SQL 必须确认含"未删除"条件，缺项禁止合入 |
| 数据 | **快照精度**：见 §1.3-11 |
| 性能 | **性能审查**：涉及金额统计的查询上线前须 `EXPLAIN ANALYZE` 确认**无全表扫描** |
| 性能 | **N+1 禁止**：严禁循环内逐条查询；批量必须 `JOIN` / `IN`（**代码审查一票否决**） |
| 协作 | **变更控制**：单次 bug 修复的改动范围限制在**单模块 / 单文件**；改共享函数须验证**所有调用方** |
| 协作 | **边界审查**：所有金额计算函数须在函数体首行标注「已人工验证边界」，缺标注禁止合入 |
| 协作 | **测试合入纪律**：自动化测试**全绿才能合入** |
