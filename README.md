## 七、⭐ 怎么加一份新文档（决策树 —— 先走这里，⛔ 别直接建文件）

1. **能用既有文档承载吗？** 能 ⇒ ⛔ 别新建（`plans/` 只许一份 · **根 md 只许本文件 ＋ `AGENTS.md`**）。
2. 是"过程 / 事故 / 逐次定案"吗？ ⇒ **`memory/journal/<今天>.md`**（append-only）。
3. 是"每轮都要遵守/要跑的规则"吗？ ⇒ **`MEMORY.md`**（⚠️ 它会超预算 ⇒ 先看能不能化成一句 + 指针）。
4. 是**工作记录五类之一**吗？（⭐ 2026-09-22 新增 —— 先看 `.codebuddy/work/README.md` 的落点总表）：
   - 构思/草稿 → `work/00-scratch/`（TTL 14 天）；
   - 方案设计 → `work/10-designs/`；实验/实测 → `work/30-troubleshooting/`（`实验-` 前缀；＋脚本 `tools/probe/`）；
   - 排查/事故 → `work/30-troubleshooting/`；拍板的决策 → `work/40-decisions/D<编号>`；
5. 是"实测出来的结论"吗？ ⇒ **`ops/<主题>-实测结论.md`** ＋ **在 `ops/README.md` 加一行索引**。
6. 是"一次性的报告/建议"吗？ ⇒ **`artifacts/`** ＋ ⭐ **必须带「待办登记回执」**（每条写"已登记为
   `TAIL-xx`"或"不登记的理由"）—— `T11` 守。
7. 是"环境/部署/配置/架构知识"吗？ ⇒ **`ops/architecture.md`** ＋ **`ops/README.md`**（随变更同批改）。
8. 以上都不是 ⇒ ⚠️ **先停下来问用户**（可能是新层级，要同时改本文件与 `T12` 白名单）—— ⛔ 问之前先查 **`ops/docs-governance.md`**（文档治理总纲 · 本体系的唯一总图）：它若已给了落点，照它办；它也答不上 ⇒ 才是真需要用户拍。

## 八、三条常见坑（都踩过）

- ⚠️ **`MEMORY.md` 是唯一被自动读到的文件** —— 写进别处但没写进它 = **下个会话读不到**。
- ⚠️ **交付面是 WPS 云同步树**（改名/删除会被**回退**，实测过一次）⇒ ⛔ 别在交付面建新文件、别做备份。
- ⚠️ **量文档行数别用 PowerShell** —— `Get-Content` **默认不按 UTF-8 解码** ⇒ 中文被拆错、**行数全错**（2026-09-24 实测 69 vs 真值 198）；`Measure-Object -Line` 另**不数空行**。真值用 `len(text.splitlines())`。
