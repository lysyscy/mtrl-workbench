# MiSans 网页字体

正式网页统一使用小米官方 MiSans 主字库 **4.009**，不是 MiSans Latin 4.007。
原始来源：<https://hyperos.mi.com/font-download/MiSans.zip>。

三个 WOFF2 文件保持官方原版字节，分别对应 Regular 400、Medium 500、Semibold 600。
由本站 `/static/fonts/` 提供，主题样式声明字体；访问者无需安装字体或连接外部 CDN。
正文与数字共用 MiSans，金额使用等宽数字和右对齐，汇总使用较强字重；字号继续响应界面档位。
Excel 导出、模板和打印版式拥有各自字体，本资源不改变它们。

版权声明见 [COPYRIGHT.txt](COPYRIGHT.txt)，完整许可见 [MiSans-License.pdf](MiSans-License.pdf)。
分发时保留两份原件和原版字体字节；许可条款以 PDF 原文为准，可从站内
`/static/fonts/MiSans-License.pdf` 获取。
