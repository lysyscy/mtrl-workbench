### 前序确认与当前修正

- 主卡由用户持有，负责充值、开票、圈存操作，只作管理关系的显示信息；本业务金额归副卡及用卡账户。旧台账标在主卡上的记录不是主卡独立账务的依据，真实接续仍保原始记录并核映射。
- 核对页采用可折叠父子分组：主卡父行只显示卡信息，副卡/用卡账户子行显示项目及金额，默认展开。父行和子行都有自由编辑的普通备注列；主卡备注跟主卡，子行备注跟用卡账户，充值与发票各笔备注分别保存。
- 核对页纳入已确认期初及完整历史账务，只保账户状态筛选，退出核对页列筛选试点。2026-10-31已确认充值包含调整、开票另列并核对差额，不再分列净充值与纯平账。只有用油联动选择核算月，充值和发票在各自日期列筛选。
- 前序用AG Grid与Univer对照框选复制、粘贴和拖填；用户已选定AG Grid。表结构和自动列固定，具体编辑方式按本轮字段用途收束，优先复用现成组件与项目既有能力。
- 充值侧默认显示“新增充值”主按钮及“转账”独立次级按钮，转账不收进下拉菜单；发票侧默认“收票”。选中行后在顶部显示适用动作，右键提供相同入口。合并开票时才出现“分给多个项目”，退出逐行重复按钮及表下大段说明。
- 单格和多格粘贴/拖填完成后均自动保存，正常静默，失败及未知结果沿原草稿保护；不增加“保存这批修改”按钮。充值/发票页合计跟筛选，台账仍导出全部有效记录，导出入口明确全量范围；首页累计不受明细筛选影响，原件下载按明确选择的票据办理。

业务与操作约定的唯一正文归[油卡需求](../../docs/requirements/oil-cards.md#工作区与表格试点)，本轮最新裁定替代前序金额和布局约定。AG组件选择已结束，逐列规则及统一金额仍在访谈；本文件不代表批准旧图或启动业务实现。

## 任务与成功标准

- 使用者是熟悉材料业务的桌面用户，访客模式为Operate；主要处理充值、收票与账务核对。
- 首次进入先看账户核对；从汇总记录直接切到对应充值或发票，返回保原范围和位置。
- 链接或PDF进入同一收票流程：明确归属的自动归档登记，异常逐票处理，重复输入不重复记账。
- 两处用油自定义金额及各自备注集中在油卡页，特殊费用与会议大表消费联动结果。

## 工作区与标签

侧栏增加一个“油卡管理”入口，沿现有导航注册和分组。工作表标签置顶；充值与发票合为同一个双表工作页，其余工作表沿各自主任务。各表筛选只影响本表明确标示的对象和期间。

| 工作表 | 主任务 |
| --- | --- |
| 账户核对（默认） | 主卡信息父行与副卡/账户金额子行，默认展开，逐行备注；完整历史账务，充值包含调整、开票另列并核对差额，不分净充值与纯平账。只保账户状态筛选，选中行后显示适用动作并有右键入口。 |
| 充值与发票 | 左侧充值/调账，右侧发票，左右均分、各自操作，筛选、排序、选择、滚动及合计互不联动。充值侧保新增主按钮及转账次级按钮，表内新增草稿自动入账，调拨成对更正/撤销；发票提供链接接收、上传PDF、人工补正、原件查看及规范命名导出。批次收票不因筛选丢掉未归属发票。 |
| 用油联动 | 按项目/月维护特殊费用当月自定义额及备注、大表截至该月额外自定义额及备注；自动部分和结果只读可核，带入来源与本月新填可辨。 |
| 用卡账户 | 账户命名、项目归属、关联卡片、在用/归档及重新启用；归档账户可人工补挂迟到发票。 |
| 实体油卡 | 完整文本卡号、主副卡、换卡及关联历史；未知可占位，改当前关联不改变历史账务。 |

“分页”按工作表标签切换落实。普通长表沿既有滚动/分页能力；标签切换不改变记录、合计及导出范围。

## 关键操作

1. **核对与登记：**选范围 → 查看账户核对 → 切到充值与发票页，在对应一侧处理 → 返回原位置。各表保自己的筛选、排序、滚动和草稿，沿当前账号已有状态机制。
2. **批次收票：**进入发票 → 粘贴链接或选PDF → 明确执行接收 → 逐票显示结果。歧义、识别不可靠和同票冲突留待处理；结果未知先核对，成功项不重复写入。
3. **一票多归属：**打开该票的集中确认界面 → 对照原件和字段 → 分配到账户 → 合计等于票面金额后整体保存。任务弹窗服务一次完整确认，不把主工作区变回上下双表。
4. **用油联动：**选项目/月 → 核自动组成 → 输入两处自定义额和备注 → 沿既定保存机制核对结果。特殊费用额按月发生；大表额与对应备注沿最近值，填0终止旧值带入。自动充值包括调整与转入转出，开票不冲减报表。原两张报表不保留第二个金额编辑入口。
5. **档案调整：**在各档案工作表维护账户、实体卡和关联；归档退出自动匹配，历史与人工补挂保留。更正接入操作历史及安全撤销。

## 布局与约束

- 同一主工作区展示当前工作页；充值与发票在同一页内左右均分，两表独立，不按行配对或相互筛选，不增加临时展开单表模式。其他明细通过切页或按任务打开集中确认界面取得。
- 顶部标签紧凑、当前页可辨；窄窗口保标签和主要动作可达。表格按任务宽高安排，短表合计跟末行，长表沿本表滚动，空间不足沿既有列宽机制。
- 采用现行AG Grid Community，Univer对照已结束。保Ant Design、MiSans、八主题、字号及列宽偏好目标；优先复用项目既有表格、付款通知书页的适配方式及成熟组件能力，按实际内容处理列宽，不把原型固定列宽估算作为布局门槛，不增加自写跨格键盘或整块操作引擎。
- 自定义额按项目/月管理，不按子账户拆开保存；账户切换不改变项目的自定义额，页面和导出用同一业务结果。
- 本轮不改全站布局、不接管中石化网页开票、不导入真实账务。实施、真实接续及正式加载各按原授权边界。
