# TAIL-414: 库存查询调整与撤销

**What to build:** 人工触发库存抓取，查询库存，办理调整和撤销并导出。

**Blocked by:** TAIL-400

**Status:** ready-for-agent

- [ ] 抓取入口沿明确事件与外部边界约束，列表、筛选、调整单及撤销入口按现行职责工作。
- [ ] 差异由库存调整单承载，保留原始来源、权限、金额/数量校验和撤销冲突提示。
- [ ] 隔离与外部响应替身验证成功、拒绝、撤销、失败回滚及有关页面刷新，不恢复独立差异页或手动导入。
- [ ] 实际导出文件与当前范围的库存、调整结果及顺序核对。
