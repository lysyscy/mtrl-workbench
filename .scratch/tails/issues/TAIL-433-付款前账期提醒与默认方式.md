# TAIL-433: 付款前账期提醒与默认方式

**What to build:** 付款人在旧付款窗口按所选付款日期看到未满账期的合同提醒，并优先采用已确认付款计划方式；新前端以后复用同一后端结果。

**Blocked by:** TAIL-432

**Status:** done

- [x] 后端统一按发票子表日期、合同最大账期及所选付款日期判断；有贸易公司的合同采用贸易发票，否则采用供应商发票。
- [x] 付款日期不晚于发票日期加x+y天时提醒，超过后不提醒；90±10天的第100天与第101天、修改付款日期后的结果均有定向验证。
- [x] 多张发票只要存在未满账期的一张，就显示合同层面核对提示及日期依据；不推断发票分摊，不计算到期可付金额。
- [x] 已付清／无欠款、无账期或无对应发票不产生账期提醒；不增加日期真实性标志或日期待核实状态。
- [x] 提醒允许继续付款，不改变既有余额、金额、幂等和事务校验；用隔离数据验证。
- [x] 付款窗口初始方式依次采用已确认计划、合同约定、现汇；空拟方式的默认现汇不代表约定。窗口手动改选后不被刷新覆盖，历史实际流水不被合同变更影响。
- [x] 旧前端调用统一后端能力，覆盖提示及手动改选的交互；同步现行付款需求，交接具体接口、响应和默认值来源，便于新前端接入。
