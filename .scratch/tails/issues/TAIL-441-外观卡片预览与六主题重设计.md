# TAIL-441: 外观卡片预览与六主题重设计

**What to build:** 外观卡片预览与六主题重设计

**Blocked by:** TAIL-425

前置身份：[本React工作树的通用导入后端退役清理](TAIL-425-通用导入后端退役清理.md)，不是master MiniApp同号票。

**Status:** blocked

- [ ] 先交付只读设计样板：六套使用同一组合成台账、完整金额、侧栏、表头、按钮、输入框、选中/焦点与成功/警告/危险状态；有四档界面大小样本，不写账号偏好或业务数据。与Carbon/Spectrum等官方参考说明设计借鉴关系，不能仅改主题名称或按钮主色。
- [ ] 六套方向为中性浅色、原版松绿、暖色纸面、深侧栏、深色、高对比。松绿保留原版整套配色和层次；其余方案有明显区别但保布局、MiSans和业务语义。用户实际看过并认可样板后才进入正式接线；未认可保持未完成，不能只凭色值差异验收。
- [ ] 正式外观设置采用主题缩略界面卡、实际尺寸样本卡。预览必须与最终React实际呈现相符，不直接把旧版API色板冒当重设计后的效果；复用既有主题主人和控件能力，不新增组件库或另一套业务颜色定义。
- [ ] 点击卡片立即按现有账号接口保存，反馈实际保存成功/失败、当前选中和保存中状态；保留身份保护、键盘操作、焦点和失败后恢复能力。刷新保持已保存选择，账号之间不串用；不新增统一应用/取消流程。
- [ ] 保留现有四档1/1.12/1.25/1.4整体缩放，文字、控件、表格行高一起变化；样本能直接区分，不改成仅文字缩放，也不与浏览器缩放混用。
- [ ] 被移除的旧主题在新版显示/选中效果统一回新版默认主题；仍保留的主题维持对应选择。不批量改写账号偏好；用户主动选择新卡片时才沿原保存出口写当前账号。旧壳保原主题定义，不承诺原本共享的账号偏好已被拆成两份。
- [ ] 按影响验证六主题卡片/实际页面的一致性、原版松绿保留、旧主题默认回退、四档字号及保存/失败/刷新/换号；代表性长表和窄屏/最大档核金额与控件可达，保持业务状态含义与现有流程。完成类型/构建及必要受影响回归，不为纯外观穷举无关业务组合。
- [ ] 用户完成样板和接线效果验看，保存当前实现/验证/未验边界；移除无消费者的一次性样板和资源。没有正式切换、生产重启、真实业务/外部动作或旧版退役授权，不修改8060在用实例。
