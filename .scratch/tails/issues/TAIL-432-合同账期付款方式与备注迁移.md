# TAIL-432: 合同账期付款方式与备注迁移

**What to build:** 使用者可在旧集采台账维护独立账期和合同付款方式，重新抓取不覆盖人工值，并可核对备注迁移前后内容后再决定真实回写。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 合同台账与读写接口支持账期和付款方式；账期按x±y天表达、以x+y自然日计算，固定天数可规范化为x±0天；方式复用现汇、承兑、供应链、其他，空值表示未填约定。
- [ ] 使用独立测试库或schema验证字段持久化、输入校验及迁移；已停用的旧付款条件字段不能直接当作四值付款方式。
- [ ] 后续抓取或导入保留人工维护的账期、付款方式和剩余备注；旧合同与发票金额、实际付款流水不因字段新增而改变。
- [ ] 备注迁移只提取明确片段，银承／银行承兑归承兑，保留质保金、阶段条款及模糊表达；不覆盖已填新字段，重复执行不继续破坏备注。
- [ ] 提供实际合同的迁移前后对照供用户确认；未经对照确认及正式迁移授权不改正式库。代码隔离验收与真实迁移的执行状态分别记录。
- [ ] 同步受影响的现行合同需求及接口字段契约，记录迁移编号、验证结果及提交号，供后两票和重构任务复用。
