**What to build:** 查询、新增、编辑和归档项目，维护人工归属并查看引用影响。

**Blocked by:** TAIL-399

**Status:** ready-for-human

- [x] 项目查询、手工建档、新增、编辑、归档及人工指认完成真实保存和重读，列表/详情/选择项一致更新。
- [x] 项目档案输入即时筛选，无常驻刷新/查询按钮；少量类型有现行语义颜色及文字，标题旁不重复表内信息。
- [x] 最右操作列按现行项目类型及状态提供扶正、改关键词、删除等适用动作；确认、权限和引用拒绝有效，不给不适用记录显示可执行入口。
- [x] 全局ord排序优先支持拖动，并有键盘可用的等价排序入口；保留在用/归档分界及后端顺序归一，筛选重排不将局部行号误作全局ord，具体次序服从既有后端判定，重读及项目选择顺序一致。
- [x] 项目Excel按当前筛选行集合及其显示顺序导出，实际读取文件核对，不混入操作列或未筛选项目。
- [x] “同步仓库名单”“同步常用项目列表”复用400的明确确认、冲突/顶号告知、执行和回执边界；用固定外部响应替身与隔离后端核对，挂载/重试不触发真实外部调用。
- [x] 现行唯一性、权限、引用影响及归档拒绝保留后端判定；歧义归属不自动猜选。
- [x] 切项目后草稿与回执归原对象；错误和版本冲突保留可处理输入。
- [x] 隔离库覆盖成功、无权限、冲突和有关联数据拒绝场景，失败不改变其他项目及业务数据。
