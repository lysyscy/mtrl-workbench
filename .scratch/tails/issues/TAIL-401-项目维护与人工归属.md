# TAIL-401: 项目维护与人工归属

**What to build:** 查询、新增、编辑和归档项目，维护人工归属并查看引用影响。

**Blocked by:** TAIL-399

**Status:** ready-for-agent

- [ ] 项目查询、手工建档、新增、编辑、归档及人工指认完成真实保存和重读，列表/详情/选择项一致更新。
- [ ] 项目档案输入即时筛选，无常驻刷新/查询按钮；少量类型有现行语义颜色及文字，标题旁不重复表内信息。
- [ ] 最右操作列按现行项目类型及状态提供扶正、改关键词、删除等适用动作；确认、权限和引用拒绝有效，不给不适用记录显示可执行入口。
- [ ] 全局ord排序优先支持拖动，并有键盘可用的等价排序入口；保留在用/归档分界及后端顺序归一，筛选重排不将局部行号误作全局ord，具体次序服从既有后端判定，重读及项目选择顺序一致。
- [ ] 项目Excel按当前筛选行集合及其显示顺序导出，实际读取文件核对，不混入操作列或未筛选项目。
- [ ] “同步仓库名单”“同步常用项目列表”复用400的明确确认、冲突/顶号告知、执行和回执边界；用固定外部响应替身与隔离后端核对，挂载/重试不触发真实外部调用。
- [ ] 现行唯一性、权限、引用影响及归档拒绝保留后端判定；歧义归属不自动猜选。
- [ ] 切项目后草稿与回执归原对象；错误和版本冲突保留可处理输入。
- [ ] 隔离库覆盖成功、无权限、冲突和有关联数据拒绝场景，失败不改变其他项目及业务数据。

规格：[前端独立重做规格](../../frontend-vue-rewrite/spec.md)（User Stories 10, 23, 24, 25）；业务口径：[MOD-01](../../../docs/requirements/PRD/02-功能规格/MOD-01.md)。

验证类型：浏览器可观察行为＋实际后端/隔离数据库；涉及导出时检查实际文件，涉及外部系统时使用明确替身边界。复用有效既有保障，按本票风险补缺，不重复整套检查。
