# TAIL-505: i8 无感连接与等待恢复

**Parent:** [TAIL-503](TAIL-503-i8会话统一与通知书打印规格.md) · [共同规格](../../i8-session-printing/spec.md)

**What to build:** 在用户已确认操作后自动查找、连接或恢复 i8 浏览器会话。需要用户介入时说明具体动作，完成后继续这一次尚未发出的请求。

**Blocked by:** TAIL-504

**Status:** done

- [x] 在当前浏览器配置、已授权的 i8 站点内自动选择可用标签。同站多标签无需选择；没有匹配标签且用户已发起操作时，后台打开 i8，不抢焦点，并发等待不反复开页。
- [x] 缺站点授权、登录过期和需要点扩展时显示各自的指引。授权、登录或点击完成后自动检测并建立连接，返回工作台无需再点连接。
- [x] 短时断网、休眠或标签替换后自动恢复可用连接。站点变更按新站点核对，恢复不重新登录 i8，不回落到直连。
- [x] 仅仍有效且尚未发出的已确认操作在连接就绪后自动提交一次。关闭弹窗、取消、切换模式或身份会解除等待。已发出的操作只查原结果。
- [x] 从现有通知书抓取入口，用待交付扩展的实际权限形态、模拟 i8 和可计数的请求证明免点击、后台开页、自动恢复以及一次提交。
