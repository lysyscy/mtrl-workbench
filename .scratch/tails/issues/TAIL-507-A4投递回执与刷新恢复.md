# TAIL-507: A4 投递、逐张回执与刷新恢复

**Parent:** [TAIL-503](TAIL-503-i8会话统一与通知书打印规格.md) · [共同规格](../../i8-session-printing/spec.md)

**What to build:** 将准备完成的付款通知书按 A4 投递。用户能看到每张作业的状态与失败原因，刷新后能继续查看原批进度和回执。

**Blocked by:** TAIL-506

**Status:** done

- [x] 从批量打印入口证明只对整批已准备完成的范围开始投递。出纸前验证当前打印通道能明确指定 A4，每份实际投递请求携带 A4 约束，自动分流同样受约束。
- [x] 通道无法确认 A4 时阻止投递，弹窗可选择支持 A4 的通道或导出 PDF。用替身核对 PDF 页尺寸正确、打印机默认 A4 这两种情形均不能替代作业指定纸型。
- [x] 弹窗显示真实投递进度。投递开始后刷新页面能查回同一批，服务继续原批，并恢复逐张回执与进度。
- [x] 回执区分打印机已接收、明确失败和结果待核实，记录可得的作业号。后续通道报错时保留前序原因；已接收或状态未知的单据不自动换通道重发。
