# TAIL-434: Excel核对合同付款方式

**What to build:** 付款计划核对技能在用户原Excel标出与关联合同不一致的付款方式，跳过问题行而继续正常行；经用户确认的特殊方式仍可由Excel写入计划。

**Blocked by:** TAIL-432

**Status:** ready-for-agent

- [ ] 复用核对快照和现有方法预览／确认接口，补足合同关联及约定方式上下文；普通未关联集采的计划行保持既有行为。
- [ ] 对关联集采合同的计划方式作比较；不一致时在用户原Excel按现有问题单元格和说明列机制标记，暂不回写该行方式；合同未填方式则标待核实并跳过。
- [ ] 同批正常行继续处理，问题行不会阻断整个批次；不把系统默认现汇当作i8原值或合同约定。
- [ ] 用户修正Excel或明确确认有意例外后，可通过既有确认流程回写计划方式；该已确认计划优先于合同默认方式，不增加异常审批子系统。
- [ ] 以脱敏Excel及隔离数据验证冲突跳过、正常行继续、确认例外和防过期校验；保留备份、原业务值、公式、人工批注及打印布局。
- [ ] 在项目维护源修改技能，核对现有分发绑定；源码保存、发布及实际安装状态分别报告，不直接改Agent安装副本。
- [ ] 同步现行核对规则及共享接口说明，记录验证、提交和技能分发结果，供已有Mini App核对入口复用，不另造网页核对流程。
