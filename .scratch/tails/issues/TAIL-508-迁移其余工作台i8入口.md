# TAIL-508: 迁移其余工作台 i8 入口

**Parent:** [TAIL-503](TAIL-503-i8会话统一与通知书打印规格.md) · [共同规格](../../i8-session-printing/spec.md)

**What to build:** 让其余工作台 i8 入口遵守同一会话选择和顶号确认规则，使用户在项目、报表和集采等页面得到一致的连接和失败反馈。

**Blocked by:** TAIL-504

**Status:** done

- [x] 对照共同规格盘点工作台其余实际访问 i8 的入口。覆盖通知书其他取数入口、常用项目和仓库、库存、收发结存、机械费、集采合同与应付及其关联，迁移漏项也纳入本票。
- [x] 迁移入口统一从既有会话选择执行，保留浏览器模式严格停止、在线冲突逐次确认、身份和站点检查。业务入口携带的旧顶号开关不能代替用户确认。
- [x] 从原有界面或受支持的工作台入口核对各业务代表路径的取数结果、分页、范围、采用和本地数据写入条件。本地查询类入口保持本地操作。
