# TAIL-471: 通知书与付款流水按对象核对提速

**What to build:** 让查看指定通知书、流水及付款核对集合减少无用全量读取，保持全部合法候选、原顺序与可信核对。

**Blocked by:** None

**Status:** ready-for-agent

- [ ] 固定通知书及选中集合，量单对象核对与完整集合读取的行数、体积、新鲜度、请求及装配成本，沿用原候选边界。
- [ ] 对确认热点按对象下推读取或复用同次可信缓存，保持完整合法候选、全部字段、原顺序及已撤销或失联记录。
- [ ] 空选与全量范围含义保持；付款前核对、未知写入后的权威读回和账号隔离仍可靠，不以陈旧缓存放行操作。
- [ ] 通过实际只读打开路径及必要隔离回归交付前后收益；父架构票及真实付款、外部调用状态保持独立。
