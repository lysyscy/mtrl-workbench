# TAIL-476: 验证 i8 抓取复用已有浏览器会话

**What to build:** 一个可复现的严格会话复用验证入口及去敏结论，沿现有取数与解析链核最小只读代表；不把重新登录成功当作浏览器会话复用成功。本票覆盖必要临时适配、离线保护及实际只读验证，不拆成仅写适配器的横向基础票。

**Parent:** [TAIL-475](TAIL-475-i8会话复用与稳定加载.md)

**Specification:** [i8 会话复用与页面稳定加载共同规格](../../browser-session-loading-20261103/spec.md)

**Blocked by:** None

**Status:** in-progress

- [ ] 核对目标浏览器会话的账号、组织、服务器与查询范围，保护现有标签及未保存状态；不得跨身份借用。
- [ ] 有效会话可完成具名只读对象／列表查询并核对业务结果；无会话、失效或错误目标明确停止，未调用登录或强踢，不持久导入会话，不写正式业务。
- [ ] 仅补严格模式必要离线行为覆盖，复用既有解析与会话测试经验，保留产品原有登录／缓存恢复策略。
- [ ] 记录复现步骤、去敏证据、结果与适用边界。实际条件缺失时记录未验及恢复条件，不能以离线成功关闭真实验证项；可继续其他 UI 票。

## 执行边界

本票只做已有会话的最小只读可行性验证；实际会话或接入条件缺失时保持真实验证未完成并记录恢复条件，不能用重新登录、离线成功或后端缓存命中替代。

实现、必要行为检查及具名过程证据随本票交付；复用输入与预期仍适用的已有证据，不重复扩大验证。范围、业务口径和授权以共同规格及当前项目规则为准。后续子任务默认 DSH，按当次任务核配置，不改变主会话配置。
