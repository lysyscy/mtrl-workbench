# TAIL-469: 收发结存与年度提取提速

**What to build:** 让收发结存月报和年度提取减少证实多余的读取、传输或布局成本，保持完整年度结果、历史结余及成品一致。

**Blocked by:** None

**Status:** ready-for-agent

- [ ] 分别量真实月报与年度提取的事实读取、响应字段、构造及布局成本，只改证实有收益的消费链。
- [ ] 对热点减少屏幕未消费的历史传输或重复事实读取，保持当前年完整网格、历史结余、归档和继承名单及空值与零的区别。
- [ ] 同源月报、年度提取和既有成品金额及顺序一致；短表自然结束、长表滚动、表头合计和复制范围保持。
- [ ] 按月报或年度提取的独立路径分段验收并复用有效证据；未证实的候选记录保持，不为改变现状强加布局或新依赖。
