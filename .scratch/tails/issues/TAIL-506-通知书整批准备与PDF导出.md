# TAIL-506: 通知书整批准备与 PDF 导出

**Parent:** [TAIL-503](TAIL-503-i8会话统一与通知书打印规格.md) · [共同规格](../../i8-session-printing/spec.md)

**What to build:** 用同一 i8 会话准备打印所需的整批 PDF，并在弹窗显示准备进度、异常和重新确认选项。「只导出 PDF」使用同一取数方式，沿用已有下载流程。

**Blocked by:** TAIL-504

**Status:** done

- [x] 从批量打印和只导出 PDF 的现有入口验证统一会话选择。版式、单头、明细、审批流程和签名图都使用本次会话；签名图的来源、只读请求范围和响应类型受约束。
- [x] 打印弹窗锁定用户已确认的单据范围，显示实际 PDF 准备计数。整批准备齐才交给投递，准备阶段投递次数为零。
- [x] 中途会话失效能穿透逐单和签名图容错。应有资料或签名缺失时显示异常单号、原因及已投递零张；正常版式留白沿既有规则。
- [x] 用户可重试全批，或移出异常单、重新确认后准备剩余范围。只导出 PDF 保留已有逐单结果与下载规则，下载重试不触发任何打印投递。
