# TAIL-504: 通知书抓取接入统一 i8 会话规则

**Parent:** [TAIL-503](TAIL-503-i8会话统一与通知书打印规格.md) · [共同规格](../../i8-session-printing/spec.md)

**What to build:** 让用户从现有通知书抓取入口按当前会话方式取数。选择浏览器时复用已连接的登录态，主动切到直连后遇到在线冲突时只确认本次顶号。

**Blocked by:** None

**Status:** done

- [x] 从现有通知书抓取入口用已连接的 i8 浏览器会话走通取数。默认选择浏览器，模式缺失、非法或浏览器会话失效时，此入口的直连登录和顶号次数均为零。
- [x] 主动选择工作台直连后可正常复用或建立本人直连会话。仅在 i8 报告在线冲突时弹出本次顶号确认，拒绝或取消时现有会话继续可用。
- [x] 确认只能用于原工作台身份、i8 站点、账号和操作范围，消费一次。改范围、换身份、过期、重复送达或单独传允许强踢参数均不能绕过确认。
- [x] 共享入口为后续工作台业务复用。通知书原有范围确认、取数、台账读回和权限行为通过代表验收。
