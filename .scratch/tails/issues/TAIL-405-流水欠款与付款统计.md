# TAIL-405: 流水欠款与付款统计

**What to build:** 查询流水、欠款和统计，撤销符合条件的付款，并下载同口径文件。

**Blocked by:** TAIL-402

**Status:** ready-for-agent

- [ ] 流水、欠款、统计的项目/月度/筛选及跳转通知书对应正确，空值与零值和统计金额服从后端口径。
- [ ] 撤销确认、权限、冲突及撤销后通知书/流水/历史刷新完整可用。
- [ ] 用既有付款夹具独立验证读取和撤销，不以批量付款新页面完成为前置；隔离核金额与失败回滚。
- [ ] 实际下载读取有关导出，与相同筛选范围的行集合、金额及排序核对。
