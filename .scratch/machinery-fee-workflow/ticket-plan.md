## 01 零租明细保存、确认与公司汇总联动

**What to build:** 在现有系统打开机械费工作区，按所选项目和月份维护零租明细；仅保存与确认金额有清楚区别，确认结果供表1及既有过程资料、欠款和大表共同使用。

**Blocked by:** None (can start immediately after implementation authorization).

- [ ] 保留四页位置与原型风格；表1零租金额可跳转本项目明细，取消、切页、换月清除临时筛选；显示名单和顺序可保存。
- [ ] 零租原表列序、文本日期、项目行增行、行末移除、每项目两列合计可用；待补过滤不改变完整项目合计；无重复来源按钮。
- [ ] 明细持久保存但不自动覆盖已确认月值；确认后复用现有有效金额出口，重复确认不重复累计，历史月仍可修订，既有手填路径可用。
- [ ] 无需车牌关键词名单可配置、持久保存、取消或清空；“升降”覆盖带高度的名称；名单外缺牌待补；其他缺项与税率、数量校验不因名单失效。
- [ ] 用隔离数据演示保存前／后、确认前／后、刷新、待补、税率缺失及下游读取同值；不连接生产写入或改源Excel。

## 02 包月明细与两类内租维护

**What to build:** 包月复用同一工作区完成编辑至月值确认；两类内租在表1填数并确认，累计和下游保持唯一金额来源。

**Blocked by:** 01。

- [ ] 包月按原列序编辑、增删、保存及确认，编辑页有不含税参考，原备注和车牌分开保留；没有新增独立记录页。
- [ ] 旧包月1—5月不检查原表未采集的车牌，原日期／期间按文本保留；缺数量改单价不自动产生0合价。
- [ ] 零租、包月共用关键词名单；两类含税／不含税项目合计及待补筛选一致。
- [ ] 租赁公司、工程公司内租均可直接填数、确认与修订；工程公司内租不计入两条核对关系，也不虚造设备明细或其他对齐步骤。
- [ ] 隔离验证两类内租、包月月值、历史修改、明细与已采用值不一致时保护，以及既有手填／下游兼容。

## 03 原报录入预览、历史接续与修订冲突保护

**What to build:** 用户与外部Agent整理原报后，通过系统同口径接口预览并确认录入；初始化真实历史和后续整份修订都有明确来源及人工冲突保护。

**Blocked by:** 02。

- [ ] 共享预览／确认入口接收项目、月份、类别、明细及原报坐标／原文；项目映射不明确不猜，确认具有重复提交保护。
- [ ] 只在用户确认后采用；逐字段三方比较，双方异值、拆合行或不确定对应逐项待确认，不能按位置或同额猜去重。
- [ ] 隔离载入1—9月1966条，保留各月原报值、最新年度参考、系统采用值及固定i6；当前累计不叠加每个月报累计，历史修订不双加。
- [ ] 保留并展示沭阳、晋江历史冲突，保护龙源已有内租、工程公司内租冲突及国风采用约定；慧能附属行不重复计费。
- [ ] 原文件哈希不变；批次可追溯，重复采用结果一致，后续人工修正不被旧原报覆盖；不接后台Agent或承诺任意Excel自动识别。

**What to build:** 用户集中取i8完整数据并看当前累计，两侧金额可直接比较；项目后续补办时只更新该项目，其他项目不动。

**Blocked by:** 03。

- [ ] 复用既有i8身份与权限边界，读取三类来源并检查完整性；班组消耗采用审批金额，结算额同时保留，未知金额不充0。

## 05 差额长期忽略与轻量核对事项

**What to build:** 用户一键忽略已接受的差额，今后只处理新增部分；单据两额不同独立处理，项目跟进只需一句事项备注。

**Blocked by:** 04。

- [ ] 按项目与核对关系持久记录忽略额度及撤销；不改左右原金额。忽略0.12后出现100.12只提示新增100，原差额0不制造待处理项。
- [ ] 刷新、重开及重复取数不恢复已忽略额度；原始差额与留底在依据查看，不把待处理额冒充原始差额。
- [ ] 两额不同逐单显示真实结算额、审批额，红字可辨；单据按本次两额事实独立忽略／撤销，金额变化重新待处理。南平两类均处理后进入已对平／已忽略。
- [ ] 核对事项弹窗只需项目和一句备注；历史回复、依据及国风约定保留，保存／完成不自动改金额、忽略或伪造约定已执行；关闭回原位置。
- [ ] 隔离验证正负新增差额、无自动容差、重新打开、单据变化、撤销，以及事项与金额／忽略互不冒充。

**What to build:** 按所选项目与报表月份，从已保存、已确认的数据生成原四页报送Excel，网页预览与文件内容一致。

**Blocked by:** 04。无需等待05，导出的是原始业务金额／差额，不是待处理额。

- [ ] 输出公司汇总、零租月报、包月月报、年度汇总四页原格式；公司规定列序、项目分组、合计、打印区域及重复表头正确。
- [ ] 表1—3原页可预览、返回编辑；缺明细、字段待补及明细与采用额不一致如实可见，不混入未保存草稿，不补造记录。
- [ ] 当前确认版本冻结为本次文件；后续历史修订不改旧文件，真实原始差额不被忽略额改写。
- [ ] 复用现有模板和导出出口；对真实副本检查数据、样式、分页、空白与0、税率及日期文本，保留现有正常导出能力。
- [ ] Excel文件实际打开与打印预览核验；实体打印未做则如实留待验，不把网页预览当生成成功。
