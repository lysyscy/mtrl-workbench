# TAIL-271: 机械费报表导入：按月导入＋差异确认＋项目名规则表

**What to build:** 机械费报表导入：按月导入＋差异确认＋项目名规则表

**Blocked by:** TAIL-270（机械费改行内编辑）—— 覆盖口径要在同一处定稳

**Status:** ready-for-agent

- [ ] 导入时**先选月份，只导该月**；含税两值取年度汇总（当月零租费/当月包月费/当月内租费），不含税两值取明细表（零租 **I 列**/包月 **O 列**），**四列都入库**
- [ ] 导入前弹**差异清单**，确认后才覆盖；**没有差异也要弹**，明说「没有差异」并问「确认还要导入么」
- [ ] 覆盖规则 ＝ **后导入覆盖先导入**（与手录同规则）
- [ ] `MOD-14` 新增**可编辑**的项目名匹配规则表，预置**16 个有档案且在建的项目**（13 normal ＋ 3 small），⛔ 不设排除；匹配走**仓库名/展示名**，⛔ 绝不碰项目全名（大唐雷州与焦作佰利两条档案的项目全名相同）
- [ ] 匹配不上的项目名**不入库**，并在结果里列出来（本报表＝灵宝一期/ 焦作武陟县 / 广州水泥 / 广东郁南水泥厂）
- [ ] 「租分公司设备」这一列**本次不导、保留原值**；⛔ 不拿 0 冒充「没有数据」
- [ ] 历史数据由 agent 在开票时用同一套逻辑直接导入（⛔ 不做界面上的历史导入功能）
