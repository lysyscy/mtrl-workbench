## §二 结论摘要（先说人话）

1. **"会不会给错信息"这一类问题最突出**（守则里叫最高优先级）：报错时把 `GET /api/… → HTTP 500` 这种**系统内部话**直接甩给用户（**60 余处**）；顶栏每页挂一句"已接后端真实数据"、按钮写着 `API-05`、说明里写着 `§4.4.2 · DEV-P-02`、`TAIL-96`——**这些是给我们自己看的**。
2. **"加载中 / 空 / 错"三态不齐**：全站**没有一处"读取中"**（搜 `加载中|loading|spinner` = **0 命中**）⇒ 数据还没回来时，页面长得跟"确实没数据"一模一样；空态文案各页各写一份（统一件 `lgEmpty` 只在 2 个页面用过）。
3. **数字缺口径**：金额只出数字不带币种/时点（`M()` @ `index.html:686`），首页 KPI `欠款合计（三类）` 显示 `83,191,167.72` 后面跟的是"辅材 ＋ 机械 ＋ 集采 · **容差 0**"（验收术语）。
4. 好消息：**口径说明已大面积折叠**（`<details class="tip">`）、导入页的「不落库的行标在行上」＋两类标记已按 §2.7/§2.8 落地并挂判据、浮层逃出裁剪/点击命中/集采派生列等真机段全绿 ⇒ **不是推倒重来，是"点一处改一处"**。

### G1 全站没有「加载中」状态

## §六 需用户裁定（每项：事实 → 选项 → 推荐 ＋ 大白话）

### 裁定 1：顶栏那句「已接后端真实数据」留不留？

**事实**：`index.html:984` 每页标题后面都跟一句状态（已接线页写「已接后端真实数据」，未接线页写「原型态 · 数据为模拟值（尚未接后端）」）；侧栏 `:982` 同理挂徽标。机器红线：`tools/audit/ui_parity.py` U2 **要求**壳里同时存在这两句话（2026-09-24 定的"不许对真数据说假话"），另有 **6 处真机断言** ＋ **4 处 `test_wired_*`** 钉着它。

**大白话**：这句话是**给我们开发自己看的进度牌**——"这页接上真数据了、那页还是假的"。您的用户不需要知道哪页接没接后端，他只会想"**难道还有假的？**"

**选项**：
- **A 保持现状**：0 成本 0 风险；代价 = 每个页面标题都挂一句对用户无意义的话（守则 §3.6 说开发态标识要"明显但克制"）。
