## 二、现状实测：真文件 × 现有导入器（★ 这节是"为什么必须改"）

| 域 | 用真文件跑现状 | 结果 |
|---|---|---|
| `m04` | 整本导入（现状读**第 1 个 sheet**） | ⛔ **直接报错** —— 第 1 个 sheet 是「计划预收款明细」，不是付款计划 |
| `m04` | 手动指定 sheet = `材机付款计划明细` | ✅ 表头行第 1 行、认出 **7 列**；⚠️ **D 列被认成 `material_doc`（材料单据）** —— 而 r2 那格写的是「外租机械：付款通知书（编号）」⇒ **机械行的编号会被当材料编号入库**（真 bug） |
| `m06` | 三份消耗汇总表 | ⛔ **三份全部拒绝**：报「找不到表头（应同时含『核算月』与至少一个材料列名）」 |
| `m11` | 两份集采台账 `.xls` | ✅ **认得完全正确**：`detect_header → (1,2)`；拼名 20/19 列全中（`供应商合同总价` / `贸易公司发票金额` …），连「详细付款方式」也认进 `method` |

**结论**：`m11` 的两级表头引擎（唯一带拼名的）在真文件上表现最好 —— 说明**拼名这条路是对的**；
`m04/m06` 的"单行表头 + 精确列名"假设在真文件上站不住。

## 三、真文件暴露的 7 条硬需求（→ 进 `mapping.py` / 各域 spec）

| # | 现象（真文件实测） | 要求 |
|---|---|---|
| 1 | 一个工作簿 **4~11 个 sheet**，第 1 个往往不是目标表；还有**空 sheet**（`pvOg8w` / `3月底`） | 通用层出**工作表清单** ＋ **自动挑**（哪张认得出表头）＋ 用户可改；空表跳过 |
| 2 | 两级表头，且**父/子内容在三份文件间互换**：`含税`+`外租设备（零租）` vs `外租机械（含税）`+`零租` | 拼名要**同时试「父+子」「子+父」**；命中别名库即采用 |
| 3 | `.xls`（BIFF）**读不到合并区**（`xlrd` 返回空），而 `.xlsx` 有 | 两级拼名**不能只靠 `merged_cells`**：无合并信息时用「r2 有值 & r3 空 ⇒ 父级直通」的**保守回退**（⛔ 仍不做"无脑右填" —— 那会认错行，2026-09-19 踩过） |
| 4 | 同一列**两级内容 = 二选一语义**（`m04` D 列：材料 或 机械） | 映射层允许「一列 → 候选字段 ＋ **域内消歧器**」（如按编号前缀 `CL*` / `FKTZS*` 或按「科目」分块） |
| 5 | 同一时间列 6 种形态：Excel 序列号 `45444` · `20250901` · `2026.7.15` · `9月11号` · `2025.09` · `截至2026年2月底` | 日期/月份画像与解析要覆盖这 6 种；**认不出的保留原值报行号**（现在 `m06` 只接受 `2026-08 / 2026/8 / 2026.08 / 202608`） |
| 6 | 分块竖合并（`科目` 列 `B3:B24`…，值只在首格）＋ 尾部合计行（`B20:N20`、`A35:N35`） | 合并区**向下填充**（只信 `merged_cells`）；**尾部合计行**按「首格含"合计/小计"或整行落在合并区」跳过 |
| 7 | `计划预收款明细` 里有 `#REF!` 公式残值 | 归入**问题清单**（行/列/原值/原因），⛔ 不静默当空 |

## 四、别名库要收的真名（权威出处 = PRD `模板清单.md §5.3`）

`m06` 过程资料的**模板列（分组头 › 叶子）→ 页面列**，逐条照抄（⛔ 不自己发明）：

| 模板列（分组头 › 叶子） | 页面列 |
|---|---|
| — › 时间 | **核算月**（⚠️ 名不同；模板 `2026.01` vs 页面 `2026-01`） |
| 线上入库（不含税）› 主辅材 / 工具 / 劳保 | 入库主辅材 / 入库工具 / 入库劳保 |
| 线上入库（不含税）› 临时设施 / 周转材料 | 入库临时设施 / 入库周转材料 |
| 线下出库（不含税）› 主辅材 / 工具 / 劳保 | 出库主辅材 / 出库工具 / 出库劳保 |
| 线下出库（不含税）› 临时设施 / 周转材料 | 出库临时设施 / 出库周转材料 |
| — › 分公司设备 | 租分公司设备 |
| — › 内部设备 | 内租设备 |
| 外租机械（含税）› 零租 / 包月 | 外租零租含税 / 外租包月含税 |
| 外租机械（不含税）› 零租 / 包月 | 外租零租不含税 / 外租包月不含税 |
