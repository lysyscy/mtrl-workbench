## 四、本机高危坑（按代价排序 · 都是踩过的）

1. ⛔⛔ **`.json` 绝不用文本替换**（改 `验收基线.json` 会写坏成 `Invalid control character`）⇒ `json.loads` → 改 dict → `json.dumps(indent=2, ensure_ascii=False)`，**改前先 round-trip 逐字节比对**（不等就拒写）。⚠️ 读它比对**必须 `read_text(newline="")`**，否则 CRLF 折成 LF ⇒ **永远不等**。
2. ⛔ **`.ps1` 三条**：① **不能出现中文**（PS 5.1 按 GBK 读 ⇒ 乱码）⇒ 带中文的逻辑写 **Python**；② 新写/改过的 `.ps1` 存 **UTF-8 with BOM**（`tools\oneoff\_ps_bom.py`）；③ ⛔ **别在命令行里写 `$env:X=`** ⇒ 环境变量只在 `.ps1` 里设、用 `-File` 跑。⭐ **凡代码带 `$`/引号/多行，一律落成脚本文件再跑**。
3. ⭐⭐ **跑闸门的长命令照抄 `IDE-细节.md` §十一** —— ⛔ 别在聊天里现拼。
4. ⛔ **`Select-Object -First N` 会掐断上游**（变异脚本 `finally` 不跑 ⇒ 靶件留坏态）⇒ 一律 `-Last N` 或先落文件。
5. ⚠️ **`字符串 | & python 脚本` 在 PS 里喂不进 stdin** ⇒ 用 **Python `subprocess(input=…)`** 直喂。
6. ⛔ **铁律 0：绝不「读 A 写 B」** —— 只有一份工作区、**无同步步骤**；`ops/` = 工程侧底账。
7. ⛔⛔ **注释写错位置 = 静默事故**（三类）：① 壳的**模板字符串**里写 `/* … */` **不是注释** ⇒ 原样渲染上屏；② **JS 注释里不能出现注释结束符本身**；③ 注释里别写被判据/墓碑钉住的**代码字面**（会假红）。⭐ 另：⛔ 别用外部脚本改完又用编辑器工具碰同一文件（旧副本会盖回）。
