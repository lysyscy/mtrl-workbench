## 三、虚拟滚动那一层：**四条铁律**（2026-09-25 `TAIL-94` 重写后 · 每条都踩过）

- ⛔ 滚动重画**不许** `$('#view').innerHTML=…`（会把真容器 `.tw` 一起换掉 ⇒ **打断滚轮手势**）；只许换 `tbody` 的行。
- ⛔ 滚动中**零 `scrollTop` 写入**（旧"锚定回拉"顶掉用户这一格的滚轮量 ⇒ 症状「**往下能滚、往上回不来**」）。
- ⭐ 文档**总高恒定**（`n*EH`）：下垫高吸收"真高 − 估算"差量、**贴底改由上垫高吸收**（末行必须是合计行）⇒ 窗口 = `f(scrollTop)` **纯函数**（无反馈环、双向对称）。
- ⚠️ 真机验收**必须 `page.mouse.wheel`**（程序化 `scrollTop` 是假证据）；**不许在"贴底"状态**起步测"滚得动"（贴底不动**是正确行为**）；护栏要复现用户**前置状态**（焦点/筛选/滚动位）。
- ⚠️ 宿主是 `backend/app/web/index.html`（⛔ 不是 `shell/*.js`）；改前 grep 外部依赖（`VS.rows/h/base/colN/pending` · `test_shell_render.py` 五条钉 · `_mut_vs.py` 钉的行）。⚠️ **改壳后先 `node --check`**；往"看着单行"的对象字面量（如 `ACT` 条目）里插东西前先确认它**是不是多行**（插中间 ⇒ 整个对象解析失败 ⇒ 壳全废）。

## 十三、`TBL` 调用收尾的括号（⛔ 已错 4 次 · 2026-09-29 从实战蒸馏）

把「表外壳」换成一个 `TBL({…})` 调用时，`rows:` 里带 `map(...)` 的那种，**收尾是一串 5 个括号**：

```
…</tr>`; })})}</div>`,
        ↑  ↑ ↑ ↑ ↑
        │  │ │ │ └─ 关 `${`（模板里的表达式）
        │  │ │ └─── 关 `TBL(` 
        │  │ └───── 关传给 TBL 的**对象字面量**
        │  └─────── 关 `.map(`
        └────────── 关箭头函数的**块体**（语句体 `{ … return …; }`）
```

- ⛔ 我**四次**都写成 `})}`（少两个）⇒ 报错形态各不相同但同源：`Invalid regular expression: missing /`
  （因为 `TBL(` 没闭合 ⇒ 后面的 `</div>` 被当代码、`/` 被当正则起始）。

- ⛔⛔ **原型侧 Q2 不查**（原型不在壳的件清单里）⇒ 只有**交付面四检的 `_smoke`** 能抓，
  表现是**早退**：`RUN FAIL: Invalid regular expression: missing /`、**没有汇总行**（⚠️ 没汇总行 = 没跑完，不是"过了"）。
- ⭐ 记住两件事即可：**① 数括号别凭手感；② 改了原型 ⇒ 必跑 `doc_audit --ui`**。

### `FBAR`（筛选栏外壳 · `TAIL-64` P4-a · 2026-09-30）的收尾

⭐ 同族但**不同**：`FBAR` 的写法是「**只换首尾两行、栏里的控件留在原地**」——

```
    ${FBAR({body:`
      <div class="fi">…控件原样…</div>
    `})}
```
- 收尾是 **`` `})} ``**（关模板字面量 ＋ 关传给它的对象 ＋ 关函数调用 ＋ 关 `${`）—— ⛔ **不是** `TBL` 那串五连括号。
- ⭐ **渲染字节不变的原理**：`body` = 中间那段**原文**（**尾部那 4 格缩进就是 `</div>` 的缩进**）⇒
